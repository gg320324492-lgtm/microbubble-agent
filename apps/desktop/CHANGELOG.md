# CHANGELOG — 小气 · 科研工作台 桌面端

## v0.1.1-alpha（2026-09-17）

### 本地资料模块三连：知识库 / 会议档案 / 实验记录本
- **[M2-1] 本地知识库**：Markdown/TXT 本地导入（多选，重名提示不覆盖）、FTS5 全文检索
  （中文 2 字词起精准命中，片段高亮，按相关度排序）、浏览与编辑保存、删除移入系统回收站；
  完全本地运行断网全功能，原件副本留存 userData/files/knowledge/
- **[M2-2] 本地会议档案**：会议条目（标题/日期/地点/参会人）+ 纪要（Markdown）+ 转录
  （导入 .txt/.srt 或粘贴，多条可编辑）+ 附件（添加/打开/删除，删除与整会删除移入回收站）；
  全文检索覆盖标题/纪要/转录（高亮 + 命中区域标注）
- **[M3-1] 实验记录本 ELN**：实验条目（编号自动生成 EXP-YYYYMMDD-NN，删除不复用，可手改，
  撞号拒绝）+ 四态流转（草稿/进行中/已完成/已归档）与筛选 + Markdown 记录 + 附件；
  全文检索标题与记录
- **[fix] 页面缩放锁定**：触控板捏合/Ctrl+滚轮误触不再缩放页面（此前缩放会按来源持久化且
  无法用快捷键恢复）；优化：FTS 切词同步沉淀为知识库/会议/实验共用模块
- **已知问题**：附件无类型白名单；Markdown 渲染预览后置；转录无逐条删除；检索排序为
  默认相关度（未做标题加权）
