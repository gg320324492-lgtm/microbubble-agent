# CHANGELOG — 小气 · 科研工作台 桌面端

## v1.3.0（草稿 · 未发布 · 云端连接基建）

> 本版开始把**知识库与网盘**做成联网桌面应用：数据住在课题组服务器，桌面端作为原生客户端。
> 本段对应三连单的第一单（基建）：先把「连接」这件事做扎实。本地 ELN、稿件、AI、备份**保持本地优先不变**。

### 统一登录：课题组账号即登录身份

- 登录窗直接输入**课题组账号密码**（与网页端同一套账号），登录后即可使用；**本机不再需要单独建号**
- 没有账号？登录窗给出「到 mnb-lab.cn 注册」入口（用系统浏览器打开）
- **登录一次即可**：重启应用免登录直接进入；**断网也能启动使用**（联网功能按离线态提示）
- **本机历史数据自动认领**：首次用课题组账号登录时，此前的会话/知识/会议等会自动归到该账号名下，**不丢失**
- **多账号同机互不干扰**：不同课题组账号各自看自己的数据
- 「设置 · 账号」可查看当前登录身份与退出登录；**退出只清登录状态，本机数据保留**，同账号下次登录自动认领回来
- 说明：备份密码等本地设置与登录方式**互不影响**

### 可绑定课题组云端账号

- 「设置 · 关于与更新 · 云端连接」可填入课题组网页端的账号，把桌面端与你的云端身份关联起来
- 绑定成功后显示**云端用户名与连接状态**；重启应用后绑定保持，无需重复登录
- **账号密码只用于本次绑定，不保存到本地**；登录凭据以系统级加密保存（与本机其他密钥同机制）
- 「解除绑定」只清除登录状态，**本地数据不受任何影响**

### 知识库改为联网读取课题组服务器数据

- 知识库的**列表、检索、阅读、新建、编辑、删除**现在直接读写课题组服务器 —— 组员联网即用同一份数据
- **检索走服务端检索**（语义检索），比本地关键词匹配更准
- **可见性完全沿用服务端规则**：谁能看到什么由服务器决定，桌面端不自行判断、不绕过
- 未绑定账号或断网时，知识库页显示引导提示并给出「前往设置 · 云端连接」入口（不可用但不报错、不崩溃）
- 说明：**此前存在本机的旧知识库数据不会被删除**，原样保留；「旧数据迁移到云端」的工具待确认后再做

### 网盘改为联网读写课题组服务器数据

- 网盘的**浏览、上传、下载、重命名、删除**现在直接读写课题组服务器（服务器统一备份）
- **大文件分块上传 + 断点续传**：网络中断后重新上传同一文件会**从断点继续**，不必重头；上传过程有进度显示
- **可见性完全沿用服务端规则**：谁能看到什么由服务器决定，桌面端不自行判断、不绕过
- 未登录或断网时显示引导提示（文案与知识库统一，后续统一登录后自动切换为「未登录」措辞）
- 说明：本版网盘为**联网功能**，离线不可用（本地缓存列入后续规划）

### 网盘改为联网读写课题组服务器数据

- 网盘的**浏览、上传、下载、重命名、删除**现在直接读写课题组服务器（服务器统一备份）
- **大文件分块上传 + 断点续传**：网络中断后重新上传同一文件会**从断点继续**，不必重头；上传过程有进度显示
- **可见性完全沿用服务端规则**：谁能看到什么由服务器决定，桌面端不自行判断、不绕过
- 未登录或断网时显示引导提示（文案与知识库统一，后续统一登录后自动切换为「未登录」措辞）
- 说明：本版网盘为**联网功能**，离线不可用（本地缓存列入后续规划）

### 连接失败时给出可理解的提示

- 密码错、网络不通、服务器繁忙、登录过期等分别给出**中性中文提示**，不再抛原始技术报错
- 登录过期会在后台**自动续期一次**；续期也失效才提示「请重新绑定」
- 服务端要求等待时（如登录尝试过于频繁）按其要求提示剩余时间

### 说明

- 默认服务器地址为 `https://agent.mnb-lab.cn`（课题组 API 主机）；自建或局域网部署可在同一处改成自己的地址
- 默认服务器地址为 `https://agent.mnb-lab.cn`（课题组 API 主机）；自建或局域网部署可在同一处改成自己的地址
- 本版**不改动知识库与网盘界面**——远程化在后续两单（远程知识库 / 远程网盘）落地
- 绑定只做**身份关联**，暂不与本地账号体系合并权限

## v1.2.0（2026-09-21）

> 本版是 Agent 能力的一次集中硬化：**大文件读取不再撑爆上下文且模型会自己续读**、
> **长会话自动压缩早期内容**、**工具权限可记住可追溯**，另加防呆与任务清单。
> 未做任何设置的用户，体感与此前一致（默认值即旧行为）。

### 大文件读取不再撑爆上下文，且模型知道「怎么继续读」
- **读取大文件时按字节预算返回**（read_file 24KB / 搜索 16KB），超出部分**逐行整行截断**，
  不会把一个中文字拦腰切断（此前是 256KB 硬切，中文场景会切出乱码）
- **结果尾部会附一句续读提示**，模型据此**自主**带 `offset`/`length` 继续读——
  实测：读取 6.7 万字节文件后，模型自己续读了下一段，无需人工干预
- 搜索命中很多或单条很长时，改为「保留开头 + 结尾」并说明省略了多少行，
  而不是把结尾（往往是关键结论）直接丢掉
- read_file 新增 `offset` / `length` 参数（按行），与续读提示闭环

### 模型调用失败会自动重试（用户不再看到「一次失败就放弃」）
- **首个字还没吐出来之前**遇到限流/服务繁忙/网络抖动/空响应 → 后台静默重试（最多 5 次，
  1 秒起步指数退避，单次最多等 30 秒，累计最多 2 分钟），用户侧完全无感
- **一旦已经开始输出正文就不再重试**——避免把同一段话重复吐给用户
- 服务端明确要求「多久之后再试」时按其要求等待
- 报错文案统一为可理解的中文（如「模型服务当前请求过多，请稍等片刻」），
  不再把原始技术报错抛给用户；凭据失效会直接指向设置页

### 长会话不再撑爆上下文（上下文预算管理）
- **会话变长时会自动压缩早期内容**：上下文接近模型窗口上限（默认 128k 的 70%）时，
  自动把最老的轮次裁掉，裁到窗口的一半为止，让对话可以一直继续下去
- **优先做「最不伤信息」的裁剪**：先把早期工具结果的长正文按「头 + 尾」压缩（尾部结论一定保留），
  实在不够才整轮移除；整轮移除前会先请模型生成一句摘要替代，避免信息彻底丢失
- **绝不会破坏对话结构**：一轮里的「工具调用」与「工具结果」永远同去同留，
  不会出现「有结果没调用」的非法上下文（裁切后自动校验，校验不过就放弃本次裁切）
- **保留近端与目标**：最近 3 轮与最初的用户目标永不裁切
- **摘要失败不影响对话**：摘要超时或失败就退化为直接移除并留标记，不会卡住或报错
- 读取**单行超长的文件**（压缩 JSON、单行日志）时可用「按字节窗口」继续读，
  不会再只能拿到开头一段
- **预算可调**：「设置 · 关于与更新 · 上下文用量（调试）」可调整模型窗口假设、
  触发比与目标比（默认 131072 / 0.70 / 0.50，即现行为）；越界或非法值自动回退默认
- **提前留额度**：每轮开始按「预计还会产出多少工具结果」预留空间，
  减少「刚压缩完又被一轮大结果顶爆」的反复
- **预算可调**：「设置 · 关于与更新 · 上下文用量（调试）」可调整模型窗口假设、
  触发比与目标比（默认 131072 / 0.70 / 0.50，即现行为）；越界或非法值自动回退默认

### 工具权限升级为「三值 + 作用域记忆 + 可追溯」
- **三种权限值**：允许 / 每次询问 / 禁止（禁止即直接拒绝，不再弹窗）
- **记住你的选择**：确认弹窗可「仅本次 / 此工作区记住 / 全局记住」，同类操作后续不再反复打扰
- **就近优先、禁止优先**：本次会话 > 此工作区 > 全局；任一层的「禁止」都不被更近的「允许」覆盖
- **事后可追溯**：每次工具调用都记录「命中了哪条规则、有没有弹确认、你选了什么」，
  事后可回答某次操作为何被放行或拒绝
- 默认值与现行为完全一致（只读直接执行、写操作询问），未做任何设置的用户体感不变

### 防呆与可控
- **空转自动停止**：连续 3 次以完全相同参数调用同一工具 → 自动停止并说明原因
- **只读不写提醒**：连续 3 轮没有任何文件改动 → 出提示交你决定（不强制中止）
- **中止原因统一**：用户停止 / 权限拒绝 / 空转 / 退出应用 共用一套中止源，原因可查
- **进行中补充要求**：任务进行中你输入的新要求会在**轮次边界**生效，不会打断正在执行的步骤

### 工作区守则注入（AGENTS.md）
- 工作区根目录放 `AGENTS.md` 即可让助手遵循你的约定（也兼容既有 `AGENT.md`）；
  内容超过 8KB 会自动节选并提示

### 任务清单（新工具）
- 助手可用 `todowrite` 维护任务清单（待办 / 进行中 / 已完成），
  同一时刻只会有一个「进行中」，便于你一眼看清进度
- 对话里会直接渲染清单卡片：灰色待办、蓝色进行中、绿色已完成（带删除线）

### 内部：循环与传输解耦（可测试性）
- 把模型返回抽象为纯数据消息流，并新增「编排式模拟」能力：可手工编排
  文本/工具调用/失败/中止序列，离线驱动完整循环做断言（正常、中止、失败并入文、重试路径全覆盖）

## v1.1.0（2026-09-20）

### 界面简化：备份设置现在能一次看懂（首次使用者可直接配完）
- **一份密码**：全页只有一个「备份密码」，手动备份与自动备份共用。填好即自动加密保存，
  不用再点「保存」；已设置后显示「已设置 ✓ · 修改」
- **一个动作**：原来的「立即备份」与「立即备份一次」合并为唯一「立即备份」，
  与自动备份走同一条链路（同样按保留策略清理旧备份）
- **默认只露四项**：备份密码 → 备份到（目录）→ 立即备份 → 状态行。
  状态行直接回答三个问题：上次备份什么时候成功没有 ｜ 下次自动什么时候 ｜ 现在留了几份
- **进阶内容收进折叠区**：触发方式 / 等待时长 / 保留份数收进「高级选项」；
  云端配置与两个开关收进「云端异地备份（可选，默认关）」；快照列表收进「备份文件与恢复」
- **文案去术语**：界面正文不再出现 safeStorage / AES-256-GCM / Endpoint 等字样，
  「Endpoint」改为「服务器地址」，改用结果语言说明（如「备份文件已加密，没有备份密码
  任何人都无法读取」）
- 保留份数默认 7 份，可设 0–30（0 = 不自动清理）

### 新增：每日定时备份（课题组服务器共享目录模式）
- **应用运行中每天自动备份一次**，落到你配置的「备份目标目录」——本地目录、局域网共享
  目录（UNC）或映射盘均可，成员各自备份到自己子目录即可
- **两种触发方式**：默认「当天首次启动后延迟 10 分钟」（凌晨多半没开机，所以不做固定时刻
  默认）；也可改为「每天固定时刻」。**错过不补跑**，第二天再触发
- **保留策略**：同前缀只保留最近 N 份（默认 7，可设 0 = 不清理），超出删最旧。
  清理**只删本应用生成的 `workbench-*.mnbbak`**，目录里其它文件一律不动
- **失败一定看得见**：定时备份失败会弹系统通知，设置页备份区块同时显示最近一次结果与时间
- **大文件防护**：附件体积超过 1 GB 时明确报错并跳过（当前容器为整内存打包），不会静默失败
- 需先配置「备份密码」；未配置时定时备份不生效，设置页会明确提示

### 修复：登录/注册页没有窗口控制按钮
- 无边框窗口下，登录页与注册页此前**没有任何最小化/最大化/关闭按钮，也无法拖动窗口**——
  真机首装用户遇到时只能强制结束进程
- 现已补上三键与标题栏拖拽区，三键实现抽出为通用组件，与主界面标题栏**共用同一套逻辑**

### 修复：安装版数据目录错位（首装用户被历史账号锁在登录页）

  （与既有正式数据目录一致，升级无缝）
- **旧的 `@mb` 目录不做任何迁移或删除**（如确认无用请自行清理）

### 变更：更新源切换到自有域名

## v1.0.0（2026-09-19）· 首个正式版

> 从 v0.1.0 到 v1.0.0，这款「小气 · 科研工作台」走完了从骨架到成品的全程。
> 以下是 v1.0.0 的能力全景——按你会怎么用它来组织。

### 一、这是什么

一台**装在你自己电脑上的科研工作台**：把课题组的实验记录、文献知识、会议档案、稿件写作
和 AI 助手收进同一个窗口。数据存本机、断网可用，不上传云端。

### 二、六大功能模块

- **AI 助手**：多轮对话，能真正**动手读写你的文件**——不是只聊天。它会自己规划步骤、调用
  工具、看结果再决定下一步；涉及写入的操作会先弹确认框让你过目，执行全程留痕可审计。
  对话里能看到它的**思考过程**（可折叠）、**工具卡片**（调了什么、参数是什么、结果如何）
  和流式正文；随时按 Esc 中断，已生成的内容不会丢。
- **知识库**：导入文档后全文检索（标题 + 正文，中文分词），命中处高亮；支持编辑与归档。
- **实验 ELN**：实验记录的结构化留存，与知识库、稿件打通。
- **稿件**：写作工作区，支持附件管理。
- **会议**：会议档案与纪要留存。
- **设置**：账号、模型服务、工作区、桌面集成、备份与恢复、关于与更新——一处管全。

### 三、桌面原生体验

自绘标题栏 + 六项侧栏 + 状态栏常驻；**关窗最小化到托盘**、托盘菜单快捷操作、
全局快捷键唤起、系统通知。窗口缩放被刻意锁定（避免误触触控板捏合导致界面错乱）。

### 四、数据安全：备份与恢复

- 全部工作数据（数据库 + 附件）一键打包为 **AES-256-GCM 加密备份容器**（`.mnbbak`），
  用密码保护，可以拷到 U 盘、网盘带走。
- 从任一容器**完整恢复**；恢复前自动留一份当前数据快照（pre-restore 安全网），恢复错了
  还能退回来。
- **云端备份（阿里云 OSS）**：备份包可上传云端、列表查看（本地 + 云端合并展示、来源标注）、
  下载恢复、删除；支持「备份后自动上传」与「退出时自动备份」（默认关，失败不阻塞退出）。
  OSS 密钥经系统级加密存储，界面不回显。

### 五、自动更新

应用内置更新通道（v0.1.5 起）：启动后后台静默检查（不打扰、失败无声），也可以在设置页
手动「检查更新」。发现新版本会弹系统通知 + 显示版本与下载进度；**下载和安装都需要你确认，
绝不自动装**。从 v0.1.4 及更早版本升级需手动装一次，之后即可在应用内直升。

### 六、界面：宣纸暖白

v0.1.6 起全界面切换到「宣纸暖白」设计语言：米色纸感底色 + 靛墨蓝主色 + 衬线标题，
安静、书卷气，适合长时间阅读与写作。Element Plus 组件（按钮/输入/对话框/表格/开关/进度/
标签）全部对齐同一套令牌，登录页一并换新。

### 七、本版新增

### 八、稳定性
