# CHANGELOG — 小气 · 科研工作台 桌面端

## v1.0.1（2026-09-20）

### 更新下载源切到国内（本版最重要的变化）
- **[R-8] 应用内「检查更新」改为从阿里云 OSS 拉取**（`releases/` 稳定路径），
  国内用户下载更新不再需要代理，速度显著提升。GitHub 源保留为可配置回退
  （环境变量 `MNB_UPDATE_FEED_PROVIDER=github` 即可切回），代码与能力不删除
- **[R-8] feed 域名可一行切换**：更新源主机抽为常量 `UPDATE_FEED_HOST`，
  `releases.mnb-lab.cn` 短域名接入后只改这一行即全量生效
- **[R-8] 更新频道收敛为 stable**：v1.0.0 起版本号不再带 `-alpha` 后缀，
  预发布开关改为「按应用自身版本号判定」——正式版不会被 alpha/beta 误拉走，
  而预发布版本仍可正常检查（回退能力保留）
- **[R-8] 发布流水线自动镜像到 OSS**：CI 在打包与可运行性门禁通过后，
  自动把三件套（安装包 / blockmap / latest.yml）上传到 OSS `releases/` 前缀并逐个校验；
  未配置凭据时黄字警告并跳过，不影响发布

### 分发与下载页
- 下载落地页（深夜极简暗色）随版本更新到 v1.0.1，主按钮指向 OSS 国内直连

### 说明
- **存量 v1.0.0 用户**：更新源切换自 v1.0.1 起对新版生效。从 v1.0.0 升级到 v1.0.1
  仍走原通道（应用内检查更新，或到下载页手动下载）；升级完成后，后续更新即走国内 OSS
- 本版未改动缩放锁定、桌面集成（托盘/快捷键/通知）、宣纸暖白主题、备份恢复等已验收行为

## v1.0.0（2026-09-19）· 首个正式版

> 从 v0.1.0 到 v1.0.0，这款「小气 · 科研工作台」走完了从骨架到成品的全程。
> 以下是 v1.0.0 的能力全景——按你会怎么用它来组织。

### 一、这是什么

一台**装在你自己电脑上的科研工作台**：把课题组的实验记录、文献知识、会议档案、稿件写作
和 AI 助手收进同一个窗口。数据存本机、断网可用，不上传云端。

### 二、六大功能模块

- **AI 助手**：多轮对话，能真正**动手读写你的文件**——不是只聊天。它会自己规划步骤、调用
  工具、看结果再决定下一步；涉及写入的操作会先弹确认框让你过目，执行全程留痕可审计。
  对话里能看到它的**思考过程**（可折叠）、**工具卡片**（调了什么、参数是什么、结果如何）
  和流式正文；随时按 Esc 中断，已生成的内容不会丢。
- **知识库**：导入文档后全文检索（标题 + 正文，中文分词），命中处高亮；支持编辑与归档。
- **实验 ELN**：实验记录的结构化留存，与知识库、稿件打通。
- **稿件**：写作工作区，支持附件管理。
- **会议**：会议档案与纪要留存。
- **设置**：账号、模型服务、工作区、桌面集成、备份与恢复、关于与更新——一处管全。

### 三、桌面原生体验

自绘标题栏 + 六项侧栏 + 状态栏常驻；**关窗最小化到托盘**、托盘菜单快捷操作、
全局快捷键唤起、系统通知。窗口缩放被刻意锁定（避免误触触控板捏合导致界面错乱）。

### 四、数据安全：备份与恢复

- 全部工作数据（数据库 + 附件）一键打包为 **AES-256-GCM 加密备份容器**（`.mnbbak`），
  用密码保护，可以拷到 U 盘、网盘带走。
- 从任一容器**完整恢复**；恢复前自动留一份当前数据快照（pre-restore 安全网），恢复错了
  还能退回来。
- **云端备份（阿里云 OSS）**：备份包可上传云端、列表查看（本地 + 云端合并展示、来源标注）、
  下载恢复、删除；支持「备份后自动上传」与「退出时自动备份」（默认关，失败不阻塞退出）。
  OSS 密钥经系统级加密存储，界面不回显。

### 五、自动更新

应用内置更新通道（v0.1.5 起）：启动后后台静默检查（不打扰、失败无声），也可以在设置页
手动「检查更新」。发现新版本会弹系统通知 + 显示版本与下载进度；**下载和安装都需要你确认，
绝不自动装**。从 v0.1.4 及更早版本升级需手动装一次，之后即可在应用内直升。

### 六、界面：宣纸暖白

v0.1.6 起全界面切换到「宣纸暖白」设计语言：米色纸感底色 + 靛墨蓝主色 + 衬线标题，
安静、书卷气，适合长时间阅读与写作。Element Plus 组件（按钮/输入/对话框/表格/开关/进度/
标签）全部对齐同一套令牌，登录页一并换新。

### 七、本版新增

- **[V1] 用量记账**：AI 对话会记录本会话累计的 token 用量（输入 / 输出），显示在对话面板
  标题旁；每轮对话完成后累加。不显示金额（模型价格变动频繁，后续版本再评估）。
- **[V1] 发布门禁加严**：发布流水线新增**主题令牌断言**——打包产物里 Element Plus 的主色
  必须等于品牌色，否则直接拦截发布（堵住「CSS 覆盖写了却没生效」这类静默失效）。
  完整审计清单见 `apps/desktop/docs/release-audit.md`。

### 八、稳定性

测试 **355 条**全绿（含离线可跑的端到端链路）；类型检查 0 错；发布流水线自动化
（推 tag 即构建、门禁、打包、可运行性验证、发布）。
