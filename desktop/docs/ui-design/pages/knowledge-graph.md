## Components

- `GraphVisualization.vue` — force-directed graph
- `EntityList.vue` — entity list with counts
- `RelationDetail.vue` — selected relationship details
- `EntitySearch.vue` — search entities
- `GraphFilter.vue` — filter by entity type
