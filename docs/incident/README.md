# docs/incident/ — 事故与状态快照档案

## 这是什么

**历史档案，不是当前状态。** 读者要在这里找的是"某次事故当时发生了什么"，
而不是"现在该怎么做"。

## 与其他目录的分工

| 目录 | 装什么 | 权威性 |
|---|---|---|
| `CLAUDE.md` 顶部 `## 当前状态` | **现在**的项目状态 | 唯一权威 |
| `CLAUDE.md` 中段各 `##` 规范段 | 现行架构/代码质量/服务层 + **永久铁律（类 20.xx）** | 唯一权威 |
| **本目录** | 事故经过、批次收口记录、历史状态快照 | 档案，只读不改 |
| `docs/history/` | dispatch 相关历史 | 档案 |
| `docs/archived/`、`docs/_archive_2026-07-12/` | 更早的归档 | 档案 |

## 写作纪律

- 档案**只增不改**：新事故另起文件，不要改旧档案（它们记录的是当时认知，改写会失真）
- 事故结束后**先提炼铁律**到 `CLAUDE.md` 的 `## 永久铁律`，再把经过写进本目录
- 不要把"当前状态"写进本目录——那会让本目录重新变成第二个 CLAUDE.md
