## SKIP 守护实现 (conftest.py)

```python
DATABASE_URL = os.getenv("DATABASE_URL")
REDIS_URL = os.getenv("REDIS_URL")
REALENV_DB_AVAILABLE = bool(DATABASE_URL)
REALENV_REDIS_AVAILABLE = bool(REDIS_URL)
REALENV_SHOULD_SKIP = (
    bool(os.getenv("SKIP_DB_SETUP"))
    or not REALENV_DB_AVAILABLE
    or not REALENV_REDIS_AVAILABLE
)
realenv_skip_all = pytest.mark.skipif(REALENV_SHOULD_SKIP, reason=...)
```

每个 test 文件加 `pytestmark = [realenv_marker, realenv_skip_all]` 强制 SKIP.
