右键菜单 UI 一致化 — 4 种方案

现状：emoji 图标（🔄 ➕ 📂 🗑）+ 珊瑚色文字，与档案系（深青 / 墨线 / 描边图标）脱节。四案全部去 emoji，面板统一为 白卡 + 墨线 + 10px 圆角 + 大阴影，分割线归一。可以直接把鼠标放到菜单项上感受 hover。同一套样式将同时作用于 文件夹右键 / 文件右键 / 特殊项(收藏·回收站·团队盘)右键。

MENU A

档案线性图标

与树/表描边图标同语言 · 推荐
每项一枚 14px 深青描边 SVG，hover 整行浅青染色 + 文字转深青；危险项（删除）hover 才转珊瑚红。信息密度与档案气质兼得。
MENU B

纯文字极简

Notion/Linear 风 · 最克制
完全去图标，只留文字。菜单更窄更安静，靠分组线与 hover 传达层级；扫视效率略低于带图标版。
MENU C

墨色深面板

深青墨底 · 对比最强
松墨 #22302C 深底 + 浅字，hover 白色浮起；与浅色页面形成强对比，右键菜单更有"工具感"。档案系深色模式同款语言。
MENU D

分组标题 + 快捷键注

结构化 · 信息最全
§ 编号分组题头（查看 / 管理 / 危险区），部分项右侧标注行为说明或快捷键（未来键盘导航可直接复用）。最"档案台账"，菜单也最高。
§1 查看
§2 管理
§3 危险区
· 四案共同项：去掉全部 emoji；「新建子文件夹」不再用珊瑚色常亮（hover 语义色）；分割线/圆角/阴影统一；危险项只在 hover 时染色。
· 选定后同一套样式作用于 文件夹右键 / 文件右键 / 特殊项右键 全部菜单。回复字母即可（如「用 A」）。
