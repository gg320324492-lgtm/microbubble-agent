任务页 Tab（任务列表 / 垃圾桶）重设计 · 4 方案

现状的问题：垃圾桶的 20px 大图标 vs 12px mono 文字不成比例（截图里像贴了个灰色 emoji）；徽标是空悬红点（el-badge 默认形态，没利用好 trashCount 这个有用信息）；active 下划线细、与文字对比弱。四案都以现有 mono 档案语言为基底，亮暗双主题同规则。

现状三宗：① 20px 图标 + 12px 文字比例失衡　② el-badge 红点悬空、数量信息弱　③ active 2px 青线在 44px 高度里存在感弱。垃圾桶 tab 的 trashCount 是现成数据——四案都把它升级为可读的计数。
