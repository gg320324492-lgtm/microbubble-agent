A · ARCHIVE

档案页首 · 研究档案延续

与设置页/对话页完全同族的档案皮肤:纸质底、钢青强调、标本标签抬头。欢迎区从"游乐园"收敛为"卷首语",兔子缩小为角落姿态。

  • 问候区改为「卷首 · DAILY BRIEF」标本标签 + 衬线大字
  • 统计三卡横排,mono 大数字,逾期珊瑚色印章式标注
  • 兔子缩为 40px 站在草地条右端,可点但不再抢视觉
B · BRIEFING

晨报式 · 竖排快报

把仪表盘做成每天打开的"组内晨报":左侧是问候+日期的竖排报头,右侧整列是数据行。信息密度最高,适合每天扫一眼。

  • 报头 + 正文双栏,报头深色底反白,仪式感强
  • 数据用"行式清单"呈现:名称 + mono 数字 + 迷你趋势
  • 逾期行用红色下划波浪线强调,像批改作业
  • 兔子在报头右侧探头,只露上半身(耳朵+眼睛)
C · CONSOLE

驾驶舱 · 数据面板

工程感最强的方案:深色仪表台、表盘式统计、状态灯。适合喜欢"控制台"感觉的人,信息全部平铺一屏不滚动。

  • 深色底 + 发光刻度环,三个大表盘 + 状态灯
  • 任务分组折叠列表带进度条,紧凑双列
  • 顶部 mono 系统状态行(时间/在线/逾期告警)
  • 兔子变成 ASCII 风格 (^._.^) 常驻状态行末尾

  • 结构不变、只换配色:渐变橙→暖纸米黄+钢青
  • 统计卡改「档案印章」风:虚线边框+mono 数字
  • 兔子乐园保留:草地/云朵/两只兔+走路动画
  • 顺带修兔子越界碰撞,加边界约束不压文字
