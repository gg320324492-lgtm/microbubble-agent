消息编辑窗（用户消息编辑态）重设计 · 3 方案

配套已选的 E「ChatGPT 现行式」。当前编辑窗还是上一代语言：珊瑚描边 + 白/橙方块 el-button，且样式硬编码深色（亮色主题下破功）。三案都换成主题 token，双主题通用。

①样式语言过时：珊瑚 1px 描边 + 直角白「取消」/ 橙「发送」el-button，与 E 方案的灰圆角/青色/圆形语言全部脱节。　②硬编码深色：background: rgba(0,0,0,.12); color: #fff 写死，亮色主题下白字打在浅底上不可读。　③快捷键无提示：Esc 取消 / Ctrl+Enter 发送已实现但用户不可见。

ESC 取消 · CTRL+↵ 发送

保留独立 textarea 但去珊瑚转中性描边（聚焦转青），按钮改文字按钮：取消=灰字，发送=青描边药丸。改动最小，双主题 token 化。
