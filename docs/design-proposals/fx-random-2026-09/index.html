「随机」按钮动效 — 4 种提案 (可点击体验)

场景：分享弹窗「提取码」输入框右侧的随机按钮。四版都保留现在的骨架（描边图标 + 随机 字样、hover 浅青），只是点下去之后的反馈不同。每版都可以直接点「随机」体验。

FX A

图标转一圈 + 翻牌换数

轻快 · 推荐
点按瞬间图标360° 旋转，提取码整体做一次 X 轴翻牌（像翻便签）。500ms 内结束，干净利落不抢戏。

↑ 点击「随机」体验

FX B

老虎机滚动 + 扫光

最有"生成感"
图标带惯性过冲地旋转，数字区虚化滚动 + 一道浅青扫光掠过。反馈最隆重，"随机"的仪式感拉满。

↑ 点击「随机」体验

FX C

逐位翻字

数字逐个落位 · 最精致
四位数字从左到右依次弹跳落位（80ms 间隔），图标小转。最能看清"每个数字是新生成的"，实现上要把 input 换成数字格子。

↑ 点击「随机」体验

FX D

按压回弹 + 波纹 + 边框闪光

物理反馈最强
按下按钮缩到 96% + Material 波纹扩散，生成后输入框青色描边闪一下确认"新码已就位"。

↑ 点击「随机」体验

· 四案共同项：图标统一用现在的双箭头 refresh 描边；生成值仍为 4 位数字；prefers-reduced-motion 自动降级。
· 回复字母即可（如「用 B」）。
