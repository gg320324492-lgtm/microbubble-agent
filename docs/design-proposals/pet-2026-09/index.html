PET SYSTEM REDESIGN · 2026-09 · 4 CONCEPTS

顶部宠物系统 · 全新概念 4 版

不再沿用「两只会走路的 CSS 兔子」这一具象物种，而是把"养成的对象"本身换掉，给出四种不同的情感锚点与玩法深度。每版都保留你已有系统里跑得通的内核（XP / 等级 / 全组共养 / 知识库闲聊 / 里程碑庆祝），但呈现方式完全重做。

A · 推荐
CONCEPT A · LIVING MICROBUBBLE

气泡精灵「泡」

把研究对象本身养成宠物——你的宠物就是一颗活的微纳米气泡。它不是拟人动物，而是一个随课题组状态涨落、振荡、聚并的气泡。

  • 尺寸=经验值，振荡模态=活跃度，ζ电位光环颜色=近期状态（绿稳/橙急）
  • 背后半透明大泡=全组泡，个人泡在前，二者会随协作"聚并/分裂"
  • 点击=注入气体(+XP)，攒够内压会「临界崩溃→再成核」升级彩蛋
  • 悬浮读数卡显示真实科研量纲：内压 MPa / 存活 d / 稳定度 Lv
  • 最贴题、最有辨识度，别人一看就知道是你家的泡
B
CONCEPT B · PETRI ECOSYSTEM

培养皿生态

顶部是一个俯视培养皿，全组 20 人是皿中一簇簇菌落/气泡。没有单一主角，你养的是整个生态。

  • 每个人是一枚菌落，完成任务→菌落长大/连片；长期不动→培养基本色变浑
  • 中央"生长环"是全组本周完成进度，随时间扫成一圈
  • 你的菌落高亮描边，旁边标你的贡献计数
  • 弱交互、强氛围：像一块会呼吸的实验室标本，适合"抬头看一眼组里气象"
  • 可加"投料"按钮（今天做点什么）让某簇菌落当天加速
C
CONCEPT C · BUBBLE TAMAGOTCHI

泡泡桌宠 · 电子宠物机

一颗泡泡头的电子宠物坐在实验室仪表dock里，有饱食/心情/活力三条需求。你真实的行为喂它，不管它会蔫。

  • 完成任务=喂食，上传知识=清洁，连续登录=陪伴；三项任一过低宠物表情变差
  • 状态机：饱足开心 / 饿了敲碗 / 脏了打蔫 / 连续打卡发光进化
  • 复古仪器风 dock：三根量表 + 喂食/清洁/陪伴三键（映射到真实跳转）
  • 最强的"每天回来看看"留存钩子，情绪投入最高
  • 可爱但需要维护数值平衡，避免变成负担
D
CONCEPT D · CONSTELLATION ARCHIVE

成就星图 · 标本图鉴

不做单一宠物，改成随成就生长的星座 / 标本柜。每一颗星、每一枚标本=一个达成，可攀比可收藏。

  • 点亮成就→星图多一颗星并连线；里程碑成"命名星"（如"逾期清零之星"）
  • 标本柜一排可解锁徽章（对应现有 ACCESSORIES/ACHIEVEMENTS）
  • 右侧全组贡献榜（谁的星空最密），把宠物变成社交/排行机制
  • 长周期收藏驱动，无"照顾负担"；适合不爱电子宠物、爱收集的人
  • 情感锚点偏"荣誉"而非"陪伴"，氛围最冷静专业
