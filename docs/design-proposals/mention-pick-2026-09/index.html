@ 成员选择框 · 4 版方案

输入 @ 即弹出成员选择（已修复空评论文件候选池为空的 bug）。四版都可真实试玩：在输入框打 @ 触发，继续打字过滤（姓名/拼音ID 均可），↑↓ 选择、Enter 或点击插入。触发逻辑四版一致，差别在选择框的形态。

A

锚定浮层 · 紧凑列表（现状改良）

从输入框上方弹出轻量浮层：头像 + 姓名 + @ID，悬停/键盘高亮，底部键位提示。最轻、最贴现有评论区气质。

用 @姓名 提醒成员
✓ 改动最小，评论区气质不变⚠ 成员多时列表长（限高 8 项滚动）
B

搜索置顶 · 分组列表

浮层顶部自带搜索行（@后文字自动同步进去），成员按「管理员 / 成员」分组展示，底注剩余数。找人不靠盲滚。

用 @姓名 提醒成员
✓ 搜索前置 + 分组，20 人团队定位最快⚠ 浮层稍高（多一条搜索行）
C

双列网格 · 成员卡片

浮层改为 2 列成员卡片（大头像 + 姓名 + ID + 角色徽标）。视觉更丰富，点选目标大、误触少。

用 @姓名 提醒成员
✓ 卡片醒目，头像辨识度最高⚠ 同屏人数少（4-6 人/屏）
D

底部内嵌面板 · 可多选

不做浮层：输入 @ 后输入框下方展开常驻面板，全员 chips 一屏尽收，点选即插入；连续 @ 多人时面板不关闭。移动端也稳（无浮层定位问题）。

用 @姓名 提醒成员
✓ 无浮层定位/裁剪问题，多选连续 @ 最顺⚠ 常驻面板占纵向空间（选完自动收起）

注：四版均保留既有行为 — 支持姓名/拼音ID 过滤、键盘 ↑↓ Enter Esc、插入 @微信ID（唯一性防重名误提醒）、失焦自动收起。
