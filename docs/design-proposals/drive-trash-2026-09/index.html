网盘回收站重设计 · 4 方案

当前回收站还是旧「玻璃态 + 红橙 hero」皮肤，与新档案语言脱节，且有三个实打实的问题：① 红粉横幅抢戏（一个提示信息占了最重的视觉位）　② 预览/下载按钮是无效的（回收站点了只弹「无法预览，请先恢复」）　③ 没有元数据（何时删的、还剩几天可恢复，全都没有）。四案共同：横幅降为静默档案条、无效按钮换成「恢复 / 彻底删除」、补 mono 元数据、ghost 动作语言对齐操作行。

数据侧：后端文件对象本就带 deleted_at — 删除时间 + 剩余天数（30 天 retention）可直接展示，无需后端改动。主题侧：跟随批次⑩.72 亮色墨 / 暗色青 token。

四案通用：① 红粉 hero 横幅 → 静默 mono 档案条（标题 + 「30 天后自动清除」chip + 共 N 项）　② 无效的预览/下载/收藏按钮移除（原点击只弹「无法预览」toast）→ 换成 ghost「↩ 恢复」+ 危险 ghost「⌫ 彻底删除」　③ 补元数据：删除时间 + 剩余天数（后端 deleted_at 已有）　④ ghost 动作规格 = 操作行批次⑩.73 同款（26px 热区 / hover 浅灰底 + 墨青）　⑤ 暗色主题同 token 翻译（卡底 rgba(255,255,255,.028)、ghost hover 白 5%）
实施位置：DriveTrashPanel.vue（横幅 + 布局）＋ FileGrid.vue trash 上下文分支（动作按钮 / 元数据行）＋ drive-view.css（.drive-panel 旧玻璃态皮肤在 trash 场景停用）。多选批量工具栏（BatchActionToolbar）保留。
