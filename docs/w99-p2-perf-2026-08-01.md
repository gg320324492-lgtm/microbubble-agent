## 关键设计决策

### 1. 缓存 key 设计: `sha256(query)[:16]`

```python
import hashlib
digest = hashlib.sha256(query.encode("utf-8")).hexdigest()[:16]
return f"emb:q:{digest}"  # emb:q:b94d27b9934d3e08
```

**理由**:
- 16 hex 字符 = 64-bit 空间, 碰撞概率 ~1/2^64 (百万次 query 仍安全)
- 避免全 64 字符 hash 浪费 Redis 存储
- `:` 分隔符便于 Redis key pattern 清理 (`KEYS emb:q:*`)

### 2. TTL 24h

```python
QUERY_EMBEDDING_CACHE_TTL_SECONDS = 86400
```

**理由**:
- 用户重复问相似问题常见, 24h 覆盖一天工作周期
- 知识库更新频率远 < 24h (weekly), 不需要 cache invalidation
- 如果未来 KB 更新频繁, 可加 `DEL emb:q:*` 在 KB 写操作后触发

### 3. 失败 best-effort

```python
try:
    redis = await get_redis()
    cached = await redis.get(cache_key)
except Exception as e:
    logger.debug(f"[emb cache lookup miss/fail] {cache_key}: {e}")
    # 降级: 走 generate_embedding 计算
```

**理由**:
- Redis 不可用不阻塞主流程 (用户体验优先)
- 真环境 Redis 挂掉时, 系统仍能跑 (降级到每次计算)
- 与 CLAUDE.md "持久化失败必须 best-effort" 一致

### 4. W99 +5 precompute task 不消费结果

```python
vector_query_embedding_task = asyncio.create_task(
    get_or_compute_query_embedding(query, has_query_prompt=True)
)
# ... gather 3 路搜索 ...
if vector_query_embedding_task is not None:
    try:
        _ = await vector_query_embedding_task  # cache primed
    except Exception:
        pass
```

**理由**:
- precompute task 的目的是**预热缓存**, 让 `_vector_search` 内 `search_semantic` 第二次调用 `get_or_compute_query_embedding` 时**命中缓存**
- 不消费结果 (结果会通过 gather 流程自然计算得到, 不会被浪费)
- await task 是为了保证 cache 已写, 不让 task 悬挂

### 5. 性能测试 rerank 跳过

```python
await retriever.retrieve("test", top_k=5, enable_rerank=False)
```

**理由**:
- 真环境 rerank 模型加载 ~8s, 污染 P95 测试
- perf baseline 测的是**检索路径**, 不是**rerank 路径**
- rerank 性能单独测 (见 `tests/perf/test_rerank_latency.py` 留 W99 P3 backlog)
