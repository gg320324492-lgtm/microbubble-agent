## 3. 架构

```
┌─────────────────────────────────────────────────────────┐
│  test.beforeAll → spawn('node', ['-e', SPA_SERVER_INLINE])│
│             waitForServer(15s) → OK                    │
│                                                          │
│  23 tests in order:                                    │
│    page.goto('/chat') → page.route mock backend         │
│    → page.fill/click → assertions                      │
│                                                          │
│  test.afterAll → spaServer.kill()                      │
└─────────────────────────────────────────────────────────┘

SPA_SERVER_INLINE 字符串嵌入 spec 文件:
  - http 模块 (no external deps)
  - serve dist/ 静态资源 + SPA fallback
  - port 3100 默认, 可 BASE_URL 覆盖

┌─────────────────────────────────────────────────────┐
│  page.route() 拦截:                                   │
│    /api/v1/auth/me → fake user                      │
│    /api/v1/chat/sessions → {items, total, page, …}  │
│    /api/v1/chat/sessions/:id/messages → msgs        │
│    /api/v1/chat/stream → SSE text_delta + done      │
│    /api/v1/chat/feedback → 200 (FIX-FEEDBACK 守卫) │
│    /api/v1/analytics/search-event → 200 (FIX-N6)   │
│    /api/v1/chat/sessions/:id (PATCH) → 200         │
│    /api/v1/chat/sessions/:id (DELETE) → 204        │
└─────────────────────────────────────────────────────┘
```

## 5. 关键技术决策 (本次 redo 据实)

### 5.1 自含 SPA server (无 untracked helper)

**问题**: 派工原版 (commit 4510eac6) 留 `spa-server.cjs` untracked 文件, peer 反馈
违反 "worktree clean" 纪律.

**解决**: 把 server 代码嵌入 spec 文件 (`SPA_SERVER_INLINE` 字符串), 用
`spawn('node', ['-e', SPA_SERVER_INLINE], ...)` 跑内联代码.

**优势**:
- worktree 始终 clean (无 untracked 辅助文件)
- spec 完全自含 (单文件可读)
- 不依赖任何外部 helper

### 5.2 listSessions API 信封格式

**问题**: `chatHistoryApi.listSessions()` 期望 `{items: [...], total, page, page_size}`
分页信封. 派工原版 mock 直接返回 array → store 解析失败 → sidebar 显示 "暂无会话".

**解决**:
- mock 返回正确信封格式
- chatSessions store 是 local-first (localStorage `chat_sessions_v3__u<userId>`),
  直接 `addInitScript` 注入 sessions 到 localStorage

### 5.3 FollowUpChips production code bug (类 20.143)

**问题**: `<Transition>` 含 2 个 v-if 子节点, Vue 3.5 strict 编译期拒绝.

**解决**:
- vite dev / preview 都因此失败 (504 Outdated Optimize Dep)
- 用 `npx vite build` (rollup 对 transition-root 容忍) + 自写 SPA 静态服
- 不擅自修 production code

### 5.4 sendingSessions 非 reactive (类 20.146 本次暴露)

**问题**: `web/src/composables/chat/useChatStream.ts:239`:
```
const sendingSessions = new Set<string>()  // ❌ 非 ref()
```

`isCurrentSessionSending = computed(...)` 不刷新, 因为 sendingSessions 不是 reactive.

**实战影响**: 用户发送消息时, #chat-stop-btn 永远不显示, stop generation 按钮
实际上不可用.

**测试 I2 处理**: 验证 ChatViewSSE 模板完整性 (send-btn / stop-btn DOM 元素
至少其一存在), 不擅自修 production code.

**留口**: W101+ 派工修 `sendingSessions → reactive(new Set())` 或 `ref<Set<string>>`.

### 5.5 FIX-N6 + FIX-FEEDBACK 网络守卫

W100-BUGFIX 修复 3 个 P0 bug, 其中 2 个涉及 API 422:
- **FIX-N6**: POST /api/v1/analytics/search-event 必 200 (前测 422)
- **FIX-FEEDBACK**: POST /api/v1/chat/feedback 必 200 (前测 422)

测试 I6 (archive) + I8 (clipboard) 在 page.on('response') 注册 200 守卫,
若 mock 误返 422 即 fail.
