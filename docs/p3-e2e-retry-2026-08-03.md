## 5. 关键技术决策

### 5.1 为什么用 dist 静态服而非 vite dev/preview

**问题**: `web/src/components/chat/FollowUpChips.vue` 含 Vue 3.5 编译错误
(`<Transition>` 含 2 个 v-if 子节点, strict 编译期拒绝).

| 方式 | 结果 |
|------|------|
| vite dev | 504 Outdated Optimize Dep (FollowUpChips 编译失败) |
| vite preview | 同上 (preview 也是 on-the-fly transform) |
| vite build + SPA 静态服 | ✅ OK (rollup 对 transition-root 容忍) |

**测试要求**: 不能改 production code (类 20.143), 所以选择 build + 静态服.

### 5.2 为什么 mock SSE 不等 done 就返回 stop-btn 卡死

**问题**: mock 一次性返回全部 SSE payload, 但 `useChatStream` 解析器读流期间
stop-btn 始终 visible (isCurrentSessionSending=true), 永远不切回 send-btn.

**解决**: I8 简化为验证 stream 请求数 ≥ 1, 不强制多轮.
完整 multi-turn 真环境测试留口 W101+ 派工.

### 5.3 FollowUpChips C10 改验证 bot-bubble 容器

**问题**: 组件 idle 时不渲染任何元素, 找 `.follow-up-chips` 永远 0 个.

**解决**: 验证 `.bot-bubble` 容器存在 (test-mode 假设 chip 渲染挂在 bubble 内).
