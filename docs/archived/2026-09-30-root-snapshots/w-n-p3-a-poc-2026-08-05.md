### 3.3 学习曲线 (实战发现)

派生 5 条实战经验 (派工 brief 路径无预警, 实战暴露):

1. **Prisma regex 解析陷阱**: `{}` 含 `{"{}"}` 默认值需 non-greedy `.*?\n\}` 模式, `[^}]*` 遇到 `}` 提前终止.
2. **Prisma DateTime tz 行为**: Prisma DateTime 默认 `Timestamptz`, 与 SQLAlchemy `DateTime(timezone=True)` 等价, 但 Prisma 字符串字面 `@db.Timestamptz(6)` 指针到 PG 精度.
3. **Prisma 无原生 FK ondelete**: Prisma 10.x 仅支持 `references` 注解, `ondelete: SetNull` 需在 service 层手写 validate. 实战派工 1 张表无影响, 53+ 张表全栈会涉及大量手写 validate.
4. **Prisma 复合 Index 命名**: `@@index([a, b], name: "...")` Prisma 10.x 不支持, 仅 `@@index([a, b])` 不命名. 现状 SQLAlchemy 复合 Index 都命名, 迁移需统一决策.
5. **Prisma Float vs Decimal 区别**: Prisma Float 默认 Double precision, 字段定义需 Decimal 时需 `@db.Decimal(p, s)`. 现有 tasks 表 priority/score 字段需逐一映射.
