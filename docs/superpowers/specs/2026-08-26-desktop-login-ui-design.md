# Desktop 登录界面设计规格

## 状态

已确认，待实现。

## 目标

将 `Scientific Research OS` 的登录页从基础深色表单升级为面向本地科研软件的双栏入口：既清楚传达科研工作台定位，也让账号登录保持专注、易读和可信。

本次仅调整渲染层 UI、文案与反馈呈现；不改变既有登录、路由、数据库或 IPC 行为。

## 布局

桌面端采用 45/55 的双栏卡片，整页居中，最小高度填满窗口。

- 左侧为深色“实验仪器环境”身份区，显示 MicroBubble Lab、Scientific Research OS、科研价值主张与本地就绪状态。
- 右侧为明亮账号表单区，包含用户名、密码、安全登录按钮和本地数据说明。
- 卡片使用 22px 圆角、细边框与轻浮层阴影；背景保持浅雾白，不使用额外图片资产。
- 窄窗口（小于约 760px）改为纵向堆叠：身份区缩短，表单位于下方。

## 视觉语言

复用 `research-design-tokens.css` 的既有令牌：

- 身份区：`--research-instrument-950/900`、`--research-signal-green`、`--research-instrument-text`。
- 表单区：`--research-paper-0`、`--research-mist-50`、`--research-teal-700`。
- 聚焦态：青绿色 2px 描边和低强度外发光。
- 错误态：`--research-red-50/600`，保持文字对比度和错误信息可读性。
- 字体：`--research-font-ui`；科研系统名可用较紧的标题字距，但不影响中文可读性。

左侧背景可用低透明网格与圆形波纹表达设备与微纳米气泡，不引入照片或装饰性插画。

## 内容与交互

表单保留现有字段、校验与提交函数。

- 标题：`进入科研工作台`；副文案：`请使用你的本地科研账号登录。`
- 用户名标签使用“用户名”，placeholder 示例为 `researcher_01`。
- 登录按钮文本为“安全登录”；提交期间改为“登录中…”，并禁用输入与按钮。
- 本地说明：`账号和实验数据仅保存在本机。首次使用请联系系统管理员创建本地账号。`
- 表单错误在按钮下方以语义化 alert 显示；不得仅靠颜色传达错误。
- 登录成功后维持原有跳转，不新增“记住我”、找回密码或注册流程。

## 可访问性与验收

- 输入框必须保留原生 `label`、正确的 `autocomplete` 和可见的键盘聚焦态。
- 错误区使用 `role="alert"` 或同等方式让辅助技术获知状态变化。
- 文字和背景对比度至少满足常规文字 WCAG AA。
- 1440px 桌面窗口下左右视觉重心均衡，登录表单宽度不超过约 390px。
- 小于 760px 时不裁切身份文案、按钮或错误信息。
- 不改动 `onSubmit`、Pinia 登录调用或路由跳转逻辑。

## 测试策略

- 先更新/新增 LoginView 组件测试，断言品牌与本地说明存在、输入字段 label 正确、错误信息以 alert 呈现、loading 状态禁用表单。
- 先运行测试确认它因新 UI 契约缺失而失败，再实现页面。
- 运行目标 Vitest、全量 desktop unit tests、`npm run typecheck` 和 `npm run build`。
