## 根因三层（总指挥初判方向正确，执行端定位到具体机制）

1. 数据源状态读 M2-3a 独立绑定状态存储（只被已退役的绑定 IPC 置位）

3. 附带：数据源 baseUrl 提供者读旧存储 → 回落默认主机 → 请求打错服务器

## 修复要点

- `cloudUsableStateFromAuth(snapshot)`：**认证态为唯一事实源**，废除独立绑定状态存储（CLOUD_BIND IPC 退役，CLOUD_UNBIND 转为「退出登录」）
- 写入顺序：先建会话 → 再写令牌 → 再写地址
- 数据源地址改机器级键 + baseUrl 提供者每次现取
- 不变量断言（防复发）：已登录且云端身份 → 状态绝不允许 unbound；未登录 → 绝不允许 ready
- KnowledgeView 显示「服务端共 N 条」——8 vs 856 之谜的用户可见取证
