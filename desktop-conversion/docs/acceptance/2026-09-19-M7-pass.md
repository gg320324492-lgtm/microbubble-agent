## 整改披露复核（EP 特异性缺陷）

首次发布的 v0.1.6-alpha 构建于 EP 映射缺陷之上（EP 组件仍默认蓝）——打包版终验抓出 → 根因定性（`:root` 伪类与属性选择器特异性同级，EP 后加载胜出）→ 修复（`:root[data-theme]` 0,2,0 + import 序）→ 删除重发（alpha tag 政策允许 + 披露合规）→ 重发后打包版终验全 PASS。**处置全程合规，且恰好验证了新 smoke 门禁的边界**（smoke 只断言版本号，抓不到主题失效——见下）。

## 遗留 / 转办（v1.0 冲刺裁决输入）

1. **smoke 门禁增强建议（采纳，列入 v1.0 冲刺）**：smoke 步骤增加主题令牌断言（`--el-color-primary` 必须等于品牌色）——成本极低，挡住整类「CSS 覆盖静默失效」
