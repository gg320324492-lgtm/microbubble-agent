## 打回原因（缺陷 1，复测 agent 代码级坐实）

### 更新检查在 dev + feed 场景被整体跳过，且静默误报「已是最新版本」

根因链：`main/index.ts` 装配 `createElectronUpdaterPort({ feedUrl })` 未传 `forceDev` → 适配层 `forceDevUpdateConfig = Boolean(options.forceDev && feedUrl)` 恒 false → electron-updater 6.8.9 `isUpdaterActive()` 在未打包环境返回 false → `checkForUpdates()` **不发任何请求直接返回 null** → UI 误报「已是最新版本」。

复测实证：伪造 feed 服务**零请求**；两次检查均产生 Skip 日志；服务层 `envSupported` 已放行而适配层闸门自相矛盾。纯逻辑层 22 条测试全绿——缺陷精确位于单元测试不可达的装配集成点，独立复测再次证明价值。

**修复要求**：
1. 装配修复：`feedUrl` 存在时传 `forceDev: true`（或适配层等价放行），方案自选并说明
2. **诚实性**：dev 无 feed 的跳过场景，UI 状态应显示「更新检查不可用（开发环境）」而非「已是最新版本」——跳过不得伪装成正常结果
3. 锁死用例：装配断言（feedUrl 存在 → forceDev=true）+「跳过场景状态诚实性」用例
4. **复测 agent 重跑 A 组全链路**（伪造 feed：自动检查/手动检查/下载→ready），通过后本单关闭
