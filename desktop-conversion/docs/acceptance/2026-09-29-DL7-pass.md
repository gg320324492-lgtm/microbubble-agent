### 发现 1 · `buildLatestYml` 尾随多换行有损 `[低 · 潜在]`

实测（js-yaml 4.3.2 往返）：

| 入参 | 解回 | 结论 |
|---|---|---|
| `"abc"` / `"abc\n"` / `"abc\n\ndef\n"` | 逐字一致 | ✓ |
| `"abc\n\n"` | `"abc\n"` | ✗ 有损 |
| `"abc\n\n\n"` | `"abc\n"` | ✗ 有损 |
| `"\n"` | `""` | ✗ 有损 |

**生产路径不可达**：唯一调用方 `extractChangelogSection` 末尾 `replace(/[\s]+$/, '')` 剥除全部尾随空白，实测真实段落以换行结尾 = false。

**性质**：导出函数的契约缺陷。将来若有第二个调用方传原始多行文本，会静默吞掉尾部空行。
**建议**：补一条测试用例固化该行为，并在 JSDoc 写明「入参须已规范化（无尾随换行）」。**不阻塞本单**。
