## 你的任务背景

应用目前是「窗口里的好软件」，本单让它成为「桌面上的好软件」：常驻托盘、后台完成通知、全局呼出快捷键、键值守命令面板、单实例锁。R-3 报告建议已采纳：**单实例锁与缩放锁定纳入本单验收清单**。

**上一单归属教训**：交付报告中「谁做了什么」必须准确——提交归属、tag 创建者等以 git 记录为准，不得含糊表述。

技术栈约束同前：**主进程服务与单测绝不 import 依赖 Electron ABI 的模块**——托盘/通知/快捷键的 Electron 调用以**注入函数**传入（ipc.ts 装配时注入，与 trashItem/openPath 同模式），核心逻辑（命令注册表、快捷键解析、设置项）保持纯函数可离线单测。

## 交付物

### 1. 单实例锁

- `app.requestSingleInstanceLock()`：二次启动不产生新实例，聚焦已有窗口（还原最小化）
- 真机验证进目验清单；离线不可测则代码评审 + 真机项标注

### 2. 托盘（Tray）

- 托盘图标常驻（组徽），**左键单击**切换显示/隐藏主窗口；**右键菜单**：显示主窗口 / 退出
- 主窗口**关闭按钮 = 最小化到托盘**，首次托盘化弹原生通知告知（「应用已最小化到托盘，点击图标恢复」）
- settings 新增「关闭即退出」开关（默认关）：开启后关闭按钮真退出（销毁托盘）
- 托盘由注入封装（TrayAdapter），服务逻辑可测

### 3. 原生通知（Notification 注入）

- 触发点 v1：**Agent 回合完成且主窗口不可见时**通知（标题=会话标题或「AI 助手」，正文=回复首行截断），点击通知聚焦主窗口
- 通知服务注入式，测试断言「窗口可见时不通知、不可见时通知恰一次、点击回调聚焦」

### 4. 全局快捷键

- 默认 **Ctrl+Alt+M**：全局显示/隐藏主窗口（任意应用前台可呼出）
- 设置页「桌面集成」区块可查看/修改/禁用；注册失败（与其他应用冲突）降级为禁用 + 设置页红字提示
- 快捷键解析（组合键字符串 → accelerator）为纯函数；globalShortcut 注入

### 5. 命令面板（应用内 Ctrl+K）

- **命令注册表（纯逻辑类，重点可测）**：注册/注销/过滤（子串匹配，支持拼音首字母可选加分）/执行
- 内置命令：六个模块导航（AI 助手/实验 ELN/稿件/知识库/会议/设置）+ 新建实验/新建稿件/新建会议 + 退出应用
- UI：Ctrl+K 唤起遮罩面板（应用内快捷键，keydown 拦截）——输入框实时过滤、上下键选择、Enter 执行、Esc 关闭；视觉对标主流命令面板（居中卡片、选中高亮）
- **与缩放拦截共存**：Ctrl+K 不是缩放键，确认 `9d8755570` 的 before-input-event 不吞它

### 6. 设置页「桌面集成」区块

- 关闭行为开关（最小化到托盘/退出）+ 全局快捷键展示与修改 + 当前生效状态（注册成功/失败原因）

### 7. 测试（≥12，全部离线）

- 命令注册表：注册/过滤（含拼音首字母若实现）/执行回调/注销 ≥4 例
- 快捷键解析纯函数：合法组合/非法组合/冲突检测 ≥3 例
- 通知服务：可见不通知/不可见通知恰一次/点击聚焦回调 ≥2 例
- 设置项往返（关闭行为、快捷键持久化）≥2 例
- 命令面板组件：渲染过滤/键盘导航/执行 ≥2 例
- 现有 **176** 条零回归
