## 交付物

### 1. 云端 API 客户端（`src/main/services/cloud/api-client.ts` 纯逻辑 + 注入式 HTTP）

- base URL 默认 `https://mnb-lab.cn`（可配置，便于测试指向 localhost/局域网）
- 登录：POST `/api/v1/auth/login`（契约以只读调研为准）→ 存取 access/refresh 令牌
- 令牌管理：access 附带于后续请求；401/过期 → 用 refresh 静默续期一次；refresh 也失效 → 状态置「凭据失效」并提示重新绑定
- REST 错误归一化：网络错误/超时/4xx/5xx → 分类 + 中性中文文案（**原始报错只进日志**，沿 M8-1 惯例）
- 超时与单次重试：连接类错误重试 1 次（幂等 GET only）；不做激进重试

### 2. 令牌安全存储

- access/refresh 用 safeStorage 加密落 settings（沿 `backup.exitPassword` 迁移模式）；解密失败/跨实例不可解 → 视为未绑定
- 解绑 = 清除令牌与绑定状态（不删本地任何业务数据）

### 3. 设置页「云端连接」区块（最小 UI，沿 M8-2/3 既有模式）

- 未绑定：服务器地址（默认 `https://mnb-lab.cn`，高级可改）+ 账号 + 密码 + 「绑定」按钮
- 已绑定：显示服务器用户名 + 连接状态（正常/凭据失效/离线）+ 「解除绑定」
- **账号密码只经 UI 输入**，不进日志/对话/报告

### 4. 可观测性

- 连接状态事件进日志；`云端连接` IPC 查询接口（状态 + 服务器用户名 + 最近错误）

### 5. 明确范围外（后续单）

- 知识库/网盘模块的任何远程化改动（M2-3b/c）
- 令牌刷新的主动定时（本单被动续期即可）
- 与本地账号体系的权限打通（绑定 ≠ 权限合并，仅身份关联）

### 6. 测试（≥12，全部离线，HTTP 注入式）

- 绑定流程：成功（令牌落 safeStorage mock）/ 密码错 / 网络失败 ≥3
- 续期：401 → refresh 成功重放 / refresh 失效 → 凭据失效状态 ≥2
- 解绑：清理令牌与状态 ≥1
- 错误归一化：超时/4xx/5xx 分类与中性文案 ≥3
- 状态机：未绑定→已绑定→失效→重绑 ≥2
- 零回归：既有 582 条
