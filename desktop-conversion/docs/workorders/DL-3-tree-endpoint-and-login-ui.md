### 缺陷 1：网盘页面空白（阻断级）——树端点路径错误

**证据（总指挥用用户 F12 令牌实测）**：

- 网页端 F12 显示树请求名为 `tree?scope=team`，发起程序 `useFolderTree-Litsli2Rjs`

**要求**：
1. **从 `web/src` 源码只读确认最终端点**（`web/src/composables/useFolderTree.js` 或同名文件——源码里有真实 URL 与响应解析逻辑；`web/src` 只读不写）

3. **当前目录视图必须同时渲染「子文件夹」与「文件」**：子文件夹来自树中当前目录的 children（可进入），文件来自 `files?folder_id=N&view=team`（M2-3c 已实现）；根视图文件为空是正常的（团队盘根只有文件夹），但**子文件夹必须显示**——用户看到的空白页即缺这个
4. 下载/上传/面包屑通道（M2-3c 已交付）保持不动
