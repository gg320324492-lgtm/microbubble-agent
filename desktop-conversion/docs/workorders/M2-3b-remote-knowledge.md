## 交付物

### 1. 知识库远程数据源（`src/main/services/cloud/knowledge.ts` + 渲染层接入）

- 列表 / 检索 / 阅读 / 新建 / 编辑 / 删除 走父级 API（契约以只读调研为准；检索用服务端检索端点，**本地 CJK bigram 逻辑不适用于远程模式**）
- 全部经 M2-3a `requestWithAuth`（401 续期一次自动）

### 2. 可见性语义（硬要求）

- **沿用服务端 `_can_see_file`/visibility 继承语义**：客户端不自造权限、不预判可见性、不做本地过滤绕过——服务端返回什么就是什么；403/不可见按中性文案处理

### 3. 未绑定 / 离线行为

- 未绑定或断网：知识库页显示引导态（「需连接云端」+ 指向设置页云端连接区块），不可用但不崩溃
- 不做本地缓存读写（缓存列入 P2）

### 4. 本地遗留数据处理（硬边界）

- v1.2.0 的本地知识库表（knowledge_documents 等）**本单不迁移、不删除、不显示**——数据原样保留在库中
- 「本地→云端迁移工具」列入交付报告遗留项，**待总指挥/用户拍板**，不得擅自实现

### 5. 测试（≥12，全部离线，HTTP 注入式）

- 适配回放：列表/检索/详情/新建/编辑/删除的契约形状 ≥5
- 可见性：403 不可见中性处理 / visibility 字段透传 ≥2
- 链路：401 续期联动重放 / 未绑定态引导 / 断网错误 ≥3
- 协议健壮：畸形响应不崩溃 ≥2
- 零回归：604 条自动包含
