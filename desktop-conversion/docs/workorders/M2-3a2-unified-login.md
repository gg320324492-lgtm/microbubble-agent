## 交付物

### 1. 登录窗改造（`LoginView.vue` 重构 + 装配）

- 表单：服务器地址（高级折叠，默认 `https://agent.mnb-lab.cn`）+ 父级账号 + 密码 + 「登录」
- 调 `/api/v1/auth/login`（走 M2-3a 客户端）→ 成功即进入主界面，令牌入 safeStorage
- 登录失败：中性文案（沿用 M2-3a 归一化：凭据失效/网络/超时分类）
- 无父级账号 → 界面一行引导：「到 agent.mnb-lab.cn 注册」（外链打开），**本地不再提供注册**

### 2. 数据认领（首次云端登录的一次性动作）

- 云端登录成功后，检测本地库中「无主」数据（此前本地账号名下的会话/知识/网盘本地遗留等）→ 自动认领到该云端身份名下
- 认领策略（推荐轻量路线）：本地 users 表行保留但映射为「云端账号缓存」（username = 父级用户名，user_id 关联映射）；多云端账号同机登录 → 按账号隔离各自数据
- 认领一次性完成 + 结果可观测（日志/状态提示「已接入 N 条历史数据」）

### 3. 本地注册退役

- SetupView（创建管理员账号）下线；启动分流改为：有缓存令牌 → 直接进（离线宽容）；无令牌 → 登录窗
- 本地 users 表与迁移 11/12 等数据库结构**保留不删**（向前兼容）

### 4. 离线宽容（硬要求，防「断网被锁死」）

- refresh 令牌有效期内：断网可正常启动进入（用缓存身份），涉及云端的功能按离线态提示
- refresh 失效且无法联网 → 登录窗显示明确指引（联网后重新登录）；**本地数据永不因登录状态删除**

### 5. 设置页「云端连接」→「账号」语义调整

- 显示当前登录身份（服务器用户名）+ 状态 + 「退出登录」（清令牌回登录窗；**数据保留**，同账号下次登录认领回来）
- 原「绑定/解绑」交互移除（被统一登录取代）

### 6. 备份密码解耦验证（显式断言）

- 登录方式切换前后，备份密码（独立字段，safeStorage）与备份功能行为不受影响——补 ≥1 条断言

### 7. 测试（≥14，全部离线，HTTP 注入式）

- 登录：成功（令牌落库+进入主界面）/ 密码错 / 网络失败 / 空输入 ≥4
- 认领：无主数据自动认领 / 已认领不重复 / 多账号隔离 ≥3
- 离线宽容：refresh 有效期内离线进入 / 失效后拦在登录窗 ≥2
- 退役：setup 不再可达 / 无本地建号入口 ≥2
- 退出登录：清令牌回登录窗 / 数据保留 ≥2
- 备份密码解耦断言 ≥1
