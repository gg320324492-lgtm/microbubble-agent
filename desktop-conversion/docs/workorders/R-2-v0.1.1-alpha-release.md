## 你的任务背景

R-1（v0.1.0-alpha）发布后，本地核心资料模块三连交付：知识库（M2-1）、会议档案（M2-2）、实验记录本（M3-1），外加缩放加固修复。本单把它们打成第二个 alpha 版本发布。

**R-1 的两条前车之鉴（必查）**：
1. **APP_VERSION 硬编码与 package.json 脱节**（v0.1.0 首包翻车，`b10888b15` 修正）——本单两处必须同步
2. Git Bash 下 NSIS 静默参数 `/S` 会被转义成路径，需写 `//S`

## 常设红线（违反任一直接打回）

1. 保护路径零改动：`app/`、`web/`、`alembic/`、`nginx/`、`docker-compose*`、`.env`、`desktop-conversion/` 一律不碰；交付时贴 `git status --short` 自证
2. 禁止 `git add -A`；只提交：`git commit -- apps/desktop`；遇 `.git/index.lock` 等待重试，禁止删锁
3. 禁止新增任何 npm 依赖
4. 门禁：`pnpm test` **160 条零回归**（本单无功能代码，不强制新增）、`pnpm typecheck` 0 错、`pnpm build` 成功、electron-builder 产出 exe
5. 发布动作：tag 推送 + GitHub Release **直接 publish**（gh 已认证）；发布后必须自验公开可见

```markdown
## v0.1.1-alpha（2026-09-17）

### 本地资料模块三连：知识库 / 会议档案 / 实验记录本
- **[M2-1] 本地知识库**：Markdown/TXT 本地导入（多选，重名提示不覆盖）、FTS5 全文检索
  （中文 2 字词起精准命中，片段高亮，按相关度排序）、浏览与编辑保存、删除移入系统回收站；

  （导入 .txt/.srt 或粘贴，多条可编辑）+ 附件（添加/打开/删除，删除与整会删除移入回收站）；
  全文检索覆盖标题/纪要/转录（高亮 + 命中区域标注）

- **已知问题**：附件无类型白名单；Markdown 渲染预览后置；转录无逐条删除；检索排序为
  默认相关度（未做标题加权）
```
