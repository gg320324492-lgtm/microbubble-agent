# 缺陷单 DL-2：网盘文件列表缺失（只列文件夹，文件夹内文件不显示）

> 签发：总指挥 · 2026-09-24 ｜ 优先级：**高（网盘核心功能缺失）**
> 基线：`da7266e66` / 691 条（以接单实测为准）

## 症状（用户真机 + 网页端对照）

- 桌面网盘：文件夹结构同步 ✓（可进入子目录、面包屑返回 ✓），但**文件夹内的文件不显示**（进入 `肖佐林` 显示空）
- 网页端同系统：`课题组网盘/组会PPT/艾琳琳` 内有**真实文件**（如 2026.3.23 大二-艾琳琳.pptx，47.7 MB，上传者杜同贺）
- 两边目录树也存在差异（桌面根出现 `肖佐林`；web 侧栏为 `组会PPT/实验数据/项目资料`）——提示桌面调用的列表**端点或作用域**与网页端不同

## 根因分析方向（总指挥初判，执行端验证）

桌面端列了「文件夹」（`/folders` 契约）但**未调用「文件夹内文件列表」接口**（或调用的端点/参数/作用域与网页端不同）。M2-3a 契约预研已记录 `DriveService.create_file/list_files` 与 `GET /by-path` 存在——大概率是桌面端漏接 list_files 或参数错位。

## 修复要求

1. **抓网页端真实调用**（用户提供 F12 抓包：进入含文件的文件夹时，加载该文件夹内容的请求 URL/参数/响应形状）——**以此为准对齐**，不猜
2. **文件+文件夹同页列出**：桌面网盘目录页应同时显示子文件夹与文件（名称/大小/上传者/上传时间，对齐网页端列）
3. **进入文件夹 = 加载该文件夹内的文件**（按 folder_id 或 by-path，以实测契约为准）
4. **回放测试 ≥3**：文件列表契约形状 / 文件夹+文件混合列 / 空文件夹
5. **目录树差异说明**：桌面根的 `肖佐林` 与 web 的 `组会PPT/艾琳琳` 树为何不同——查清是作用域不同（个人盘 vs 团队共享盘）还是数据差异，报告说明

## ✅ 用户 F12 实测契约（2026-09-24，标准答案，以此为准对齐）

**网页端网盘（团队共享盘）实际调用（全经 `requestWithAuth` 同款 Bearer）：**

| 接口 | 实测调用 | 返回 |
| --- | --- | --- |
| 文件夹树 | `GET /api/v1/drive/tree?scope=team` | 侧栏树（组会PPT/实验数据/项目资料） |
| 文件列表（根） | `GET /api/v1/drive/files?page=1&page_size=20&sort_by=created_at&sort_order=desc&starred_only=false&view=team` | `{items:[],total:0}`（团队盘根无文件，只有子文件夹） |
| 文件列表（子目录） | 同上 **`&folder_id=336`** | `{items:[2025.9.22.pptx(115,610,891B)…],total:2}` |

- **进入子目录 = files 端点追加 `folder_id` 参数**；无 folder_id = 视图根
- 响应形状：`{items,total,page,page_size}`；item 字段：id/title/file_name/file_type/file_size/storage_mode/visibility/folder_id/folder_name/owner_name/owner_username/created_at/updated_at/is_team_shared…
- **病根确认**：桌面调用 `/folders`+自造树，**文件列表端点（/api/v1/drive/files）从未被调用** → 文件不显示；目录树不一致同因

### 修复要求（据实测契约细化）

1. 文件夹树改接 `GET /api/v1/drive/tree?scope=team`（废弃 /folders 自造树）
2. 当前目录文件列表改接 `GET /api/v1/drive/files?page=&page_size=100&sort_by=created_at&sort_order=desc&view=team&folder_id=<当前>`（根视图不带 folder_id）
3. 列表呈现对齐 web 列：名称/大小/上传者/上传时间（file_size 真实字节格式化显示）
4. 回放测试 ≥3：树契约形状 / files 契约形状（根+folder_id 两态）/ 归一化
