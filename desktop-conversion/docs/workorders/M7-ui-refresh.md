## 交付物

### 1. 设计令牌层（一次成型，全局生效）

- 以 `ui-style-proposals.html` 的 **paper 主题 CSS 变量**为唯一源头，展开为全应用令牌表：背景三级（bg/panel/card）、边框两级、文本两级、主色系（accent/accent-weak）、语义色（ok/warn/danger + weak）、圆角、阴影、衬线标题字体栈
- **全局替换珊瑚橙残留**：全仓检索旧主色值（橙色系）与珊瑚相关类名，逐处切换到宣纸令牌（登录页/空态/按钮/toast/进度条等所有出现点）
- 衬线标题：`h1/h2/h3` 与页面主标题切换衬线字体栈（Georgia + 宋体回退），正文保持无衬线
- 暗色模式本期**不做**（U4 确认）

### 2. Element Plus 主题覆盖

- EP CSS 变量映射到宣纸令牌：`--el-color-primary` 系（主色/浅阶/深阶）、`--el-border-radius-*`、`--el-font-size-*`、`--el-text-color-*`、`--el-bg-color`、`--el-fill-color-*`
- 组件级微调：button / input / dialog / messagebox（危险确认样式）/ table / switch / progress / tag——以 paper 设计稿观感为准
- 覆盖方式：EP 变量覆盖文件独立（如 `src/renderer/src/assets/ep-theme.css`），不散落各组件

### 3. 六模块一致性过检与微调

- 知识库 / 会议 / 实验 ELN / 稿件 / 设置 / AI 助手：逐页对照 paper 设计稿过检——工具条、卡片、空态、chips、状态徽标、按钮组排布一致性
- **AI 助手对话流**（消息气泡/工具卡片/思考面板/命令面板）一并换新到宣纸语言——对话是使用频率最高的界面，观感优先级最高
- SideNav：图标 tile、选中态、徽标样式过检

### 4. 登录页换新

- 珊瑚橙主色 → 靛墨蓝；双栏布局与文案保留（归档登录设计规格的结构不变）

### 5. 随车必办三项（M6-2 转办 + 遗留清账）

1. **设置页滚动缺陷修复**：矮窗口下内容不可滚动（M5-2 遗留）——修复并**全模块滚动自查**（六模块 + 设置 + 对话页在 720p 最小窗口下均可滚动）
2. **CI 可运行性门禁**（M6-2 转办）：`desktop-release.yml` 增加产物可运行性验证步骤——CI 内静默启动打包产物 + CDP 断言状态栏版本号，失败即 fail（附 M5-2 ABI 事故参照；本单为该门禁首次真实使用）
3. **版本同步一致性检查脚本化**：package.json ↔ constants.ts 版本一致性（M6-2 已建，确认纳入门禁步骤）
