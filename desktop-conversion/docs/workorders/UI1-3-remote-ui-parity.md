### 1. 知识库页原生还原（`KnowledgeView.vue` 桌面版重做）

- **信息架构对齐父级**：检索框（回车触发服务端语义检索）+ 分类/标签筛选 + 知识卡片列表（标题/分类/标签组/日期/**文档徽标**——远程知识项**不显示字节大小**）+ **分页器**（「共 X 条」+ 页码，`total > pageSize` 时显示；对齐 web「共 429 条」样式）
- **统计概要**：服务端 `/knowledge/stats` 的分类统计卡片（health-summary 对应物）
