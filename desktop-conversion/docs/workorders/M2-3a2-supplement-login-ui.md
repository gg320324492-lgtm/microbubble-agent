## 用户真机反馈（两处，均为产品缺陷）

1. **注册引导指向了不存在的功能**：登录窗显示「到 mnb-lab.cn 注册」——mnb-lab.cn 是静态站/门户，**没有注册功能**；父级系统本就**没有自助注册端点**（auth.py 仅 login/refresh/改密），账号由管理员统一创建。总指挥工单原文此处即为笔误 propagated，非执行端实现错误
2. **「高级选项 / 服务器地址」不应出现在登录窗**：普通用户不需要也不应看到服务器地址；正常登录界面 = 账号 + 密码 + 登录 + 一行「无账号联系管理员」

## 修复要求（三点）

1. **移除登录窗「高级选项 / 服务器地址」输入区**：默认地址 `https://agent.mnb-lab.cn` 内置为常量；配置覆盖能力保留在代码层（配置文件/环境变量，不在登录 UI 暴露）
2. **注册引导行改写**：`还没有课题组账号？到 mnb-lab.cn 注册` → **`还没有课题组账号？请联系管理员开通`**（纯文案，无外链；外链通道 APP_OPEN_EXTERNAL 若因此无使用方可保留通道本身）
3. **顺带文案核对**：登录窗底部「账号和数据仅保存在本机数据库」在云端登录语义下有误导——改为「登录后数据保存在本机，断网可用；账号与网页端同源」之类准确表述；全文件 grep 确认不再出现「mnb-lab.cn」作为注册引导（**注意：`https://agent.mnb-lab.cn` 为正确 API 地址，勿误伤**）
