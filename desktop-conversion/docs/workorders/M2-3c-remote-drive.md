## 交付物

### 1. 网盘远程数据源（`src/main/services/cloud/drive.ts`）

- 目录浏览 / 文件列表 / 下载 / 删除 / 重命名 走父级 API（契约以只读调研为准，含 `GET /by-path`）
- 全部经 `requestWithAuth`

### 2. 分块上传三件套（硬要求）

- `POST /drive/init` → `PUT /{uploadId}/chunks/{i}` → `POST /{uploadId}/complete`
- **断点续传**：上传会话状态持久化到 settings（uploadId/已传分块），中断后续传不重头
- **进度事件**：上传/下载进度回调进 UI（进度条），大文件不整文件进内存（分块读盘）
- 小文件（低于分块阈值）走简化路径

### 3. 可见性语义（硬要求）

- 沿用服务端 `_can_see_file` + visibility 继承校验：客户端不自造权限、不预判、不本地过滤绕过

### 4. 外部状态「提供者」模式（硬要求）

- 当前文件夹、上传会话、服务器地址等外部状态一律提供者模式（每次使用时取），**禁止构造期快照**（M2-3b 实证缺陷范式）

### 5. 归一化范式

- 服务端返回一律 `normalize*`（丢弃畸形项）再进 UI；403/不可见中性文案；协议健壮用例覆盖

### 6. 未绑定 / 离线行为

- 沿 M2-3b 引导态模式；**结构改动最小化**（教训：包裹层曾致 SFC 编译失败）——新增 DOM 挂载测试守护

### 7. 本地遗留数据硬边界

- 网盘本地遗留数据（如有）不迁移、不删除、不显示；迁移工具待拍板，不得擅自实现

### 8. 测试（≥14，全部离线，HTTP 注入式）

- 适配回放：目录列表/下载/删除/重命名契约形状 ≥4
- 分块上传：init→chunks→complete 时序 / 中断后续传 / 小文件简化路径 ≥4
- 断点续传持久化：settings 读写往返 ≥2
- 可见性：403 中性处理 / visibility 透传 ≥2
- 提供者刷新：改绑定后请求打新地址（M2-3b 同款回归）≥1
- 协议健壮：畸形响应不崩溃 ≥1
- 零回归：621 条自动包含
