## 交付物

### 1. 权限三值模型（`src/main/agent/permissions/policy.ts` 纯函数）

- 工具分类沿用现确认流分组；每类三值：`allow` / `ask` / `deny`
- **默认值 = 现行为**（只读类 allow、写类 ask）——零行为变更是硬要求
- deny 语义：该类工具直接拒绝执行（中性文案告知），不走确认

### 2. 作用域梯度（policy 存储分层 + 判定）

- 三层：**会话级**（内存，本次会话）→ **工作区级**（workspace 配置文件）→ **全局级**（设置键）
- 确认弹窗升级三选项：「仅本次 / 此工作区记住 / 全局记住」（拒绝侧同理「仅本次拒绝 / 永久拒绝」）
- 判定优先级：**deny > allow；更近作用域覆盖更远**（会话 > 工作区 > 全局）；无匹配 → 类别默认值
- 设置页新增「工具权限」区块（最小 UI）：按类别列当前生效值 + 三值下拉，展示每条的来源作用域

### 3. 证据链（`workspace/audit.service.ts` 扩展）

- 每次工具执行追加记录：命中的规则（类别/作用域/值）、是否弹确认、用户选择、时间戳、参数摘要
- 目标：任一回答里的任一工具调用，事后可回答「它为什么被允许/拒绝」

### 4. runaway guard（`src/main/agent/guards.ts` 纯函数 + 装配）

- 连续 ≥3 次**同工具同参数**调用 → 经 AbortSource 中止 + 中性提示
- 连续 ≥3 轮**无写入类进展**（无任何落盘）→ 不硬中止，出提示交用户决定

### 5. steering + AbortSource 统一

- 中止源抽象：用户停止 / 权限拒绝 / runaway 触发 / 应用退出 共用一个 AbortSource
- steering：会话进行中用户输入的即时指令在**轮边界**注入下一轮（不打断进行中的工具）

### 6. AGENTS.md 注入

- 工作区根 `AGENTS.md` 存在 → 会话开始注入 system（预算 ≤8KB，超限截断 + 一行提示）
- 文件变更后下一轮生效；与既有系统块共存，顺序稳定

### 7. todowrite 工具（第 10 个工具）

- 三态任务清单（pending/in_progress/done），会话内持久（IPC 存储）
- chat 面板清单卡片（最小 UI：状态点 + 文本 + 删除线）

### 8. 上下文收尾（M8-2 移交，小项）

- 裁切记录持久化到会话元数据（事后可复盘「某次回答为何丢上下文」）
- 预算预留：轮次开始按预计工具结果留额度，减少「刚裁完又被大结果顶爆」

### 9. 测试（≥18，全部离线）

- 权限判定矩阵：三值 × 作用域 × 优先级（deny 压 allow / 近覆盖远 / 无匹配落默认）≥6
- 证据链：规则命中记录完整 / 确认选择入链 / 时间戳与参数摘要 ≥3
- runaway：同参连击检测 / 无进展轮检测 / 触发经 AbortSource 中止 ≥3
- AGENTS.md：存在注入 / 超限截断 / 变更下轮生效 ≥2
- todowrite 状态机（合法流转 / 非法流转拒绝）≥2
- 预算预留 / 裁切记录持久化 ≥2
