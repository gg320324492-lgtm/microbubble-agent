## 交付物

### 1. 三项小硬化（各自独立或合并 commit 均可，说明清楚）

- **A. 窗口 API 补全**：`window.api.window` 增加 `show()` / `focus()`（preload + 主进程 handler，走现有 window 通道族），托盘左键/通知点击/second-instance 恢复路径统一改走显式 API；单测经注入断言调用
- **B. 快捷键冲突自动建议**：设置页注册失败（Ctrl+Alt+M 被占用类）时，自动尝试候选序列（如 Ctrl+Shift+M → Ctrl+Alt+K → Ctrl+Alt+P，逐个探测 `globalShortcut.register`），成功即红字旁绿字提示「已自动改绑为 XXX，点击确认采用」；用户确认前不落库
- **C. 死代码清理**：`shortcut.ts` 移除 `if (false)` 残留块（36-38 行）；托盘图标改用打包内 `.ico` 多尺寸（如资源已具备；不具备则维持现状并说明）
