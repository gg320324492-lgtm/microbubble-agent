# AGENT.md — Agent 行为守则

> 本文件是桌面端 Agent 在本工作区工作时的行为约束与上下文说明。
> 每次文件操作任务开始前，Agent 必须阅读并遵守本文件。

## 本工作区是什么

「小气 · 科研工作台」桌面端建设的指挥部与工作区：存放工单、验收记录、决策记录，
以及 Agent 自身的工作产出（实验性文件、整理结果、生成的文档等）。

## 建议目录约定（建议而非强制；已有结构优先，Agent 跟随现状）

```
projects/<任务名>/{data, figures, manuscript, refs, notes}
```

## 工具使用守则（必须遵守）

0. **范围锁定（最高优先级）**：本工作区只做桌面端转化相关内容；禁止读取、修改、影响上层父项目（`../` 即 microbubble-agent 开发仓库）的任何文件——尽管物理上可达，父项目内容对 Agent 不存在
1. **先读后写**：修改任何文件前必须先读它；禁止凭空臆造路径或内容
2. **edit 前必须 read**：精确替换类操作，old_string 必须来自刚读过的真实内容
3. **禁止臆造路径**：不确定就先 list_dir / glob 确认
4. **禁区**：`.git/` 目录下一切内容只读禁写（config 可能含令牌）；仓库外路径一律不可达（沙箱围栏强制）
5. **不执行 git 命令**：clone / commit / push 由人类完成，Agent 只操作工作树文件
6. **删除走回收站**：任何删除操作进系统回收站，绝不物理删除
7. **写操作留痕**：所有覆写前自动备份到 `.agent-backups/<时间戳>/`（已 gitignore，不入库）

## 完成标准

- 任务产出放在明确命名的子目录中，不散落仓库根
- 结束时向用户报告：改了什么、放在哪、如何回滚
