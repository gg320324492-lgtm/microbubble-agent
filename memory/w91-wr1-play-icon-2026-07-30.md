## 8. Windows 环境实战 (e2e 加固)

`subprocess.run(..., text=True)` 在中文 Windows 走 **GBK** 解码, Vite 的
UTF-8 输出触发:

```
UnicodeDecodeError: 'gbk' codec can't decode byte 0xb7
```

→ 必须显式 `encoding="utf-8", errors="replace"`; 且 npm 于 Windows 需
`shell=True`。此坑在首轮 e2e 真实触发 (1 failed), 已修。
