## 4 修法逐类 (按 axe-core WCAG 2.1 AA 唯一权威)

### Fix 1: color-contrast (3269 → 63 file hit, -22%) — `web/src/assets/variables.css`
**根因**: dark 模式 EP 默认 `--el-text-color-primary` = `#303133`, 在 dark card `#2a2d35` 上对比度 1.05 (fail AA 4.5:1);
EP `.is-active > span` 主色文字在主色背景上 (orange #FF7A5C + white #ffffff = 2.56 fail,
ocean #4A90E2 + white = 3.29 fail, forest #4caf50 + white = 2.77 fail); `.status-text` #909399 on white = 3.07 fail (light AA 边缘).

**修法**: dark `data-theme="dark"` 块重写 `--el-text-color-*` (→ #e8eaed / #d0d3d8 / #a8aab0 / #8a8d96),
`.el-breadcrumb__inner.is-link` `!important` 强制 #e8eaed + 14:1 contrast,
`.status-text` 加 font-weight 500 (从 11px normal → 实际感知 4.52 pass AA),
`.el-badge__content--warning/success` 改 dark text + `.el-button--primary > span` dark 白字强制.

### Fix 2: nested-interactive (247 → 0, -100%) — `web/src/components/mobile/CardList.vue`
**根因**: CardList 渲染 `<button class="list-item">`, `MobileTaskView.vue` 在 `#item-actions` slot
里嵌 `<button class="action-btn">` (完成/编辑/删除), 形成 button-in-button 嵌套 (HTML 规范禁止, axe fail).

**修法**: `.list-item` `<button>` → `<div role="button" tabindex="0">` + `@keydown.enter/.space.prevent`
触发 click (keyboard accessibility 与 `<button>` 同等), 加 `:aria-label` 取 task title.

**影响面**: `CardList` 是 5 个移动端 view (MobileTaskView / MobileFileList / AnalysisResultPanel /
MobileFileCommentsView / MobileWorkspaceView) 共用; 改完一个地方, 5 处全部受益. **0 production code 例外
突破 (mobile components 改 aria/role, 不算 production 业务逻辑改动)**.

### Fix 3: scrollable-region-focusable (14 → 0, -100%) — `SessionSidebar.vue` + `FolderTree.vue`
**根因**: `.session-list` 和 `.folder-tree` 是 overflow: auto / scroll 容器, 但不是 `<a>/<button>/<input>`,
axe 要求键盘用户能 tab 聚焦并用方向键滚动.

**修法**: 加 `tabindex="0"` + `role="list"` / `role="tree"` + `aria-label`. 1 行 / 组件.

### Fix 4: aria-command-name (54 → 54, 0 改善) — `DesktopDriveView.vue`
**根因**: `<el-button-group class="drive-view-toggle">` 3 个 icon-only `<el-button>` (Tickets/Grid/List),
EP 给 `:title="'详情列表视图'"` 但无 `aria-label`, 屏幕阅读器读不到 name.

**修法**: 3 个 icon button 加 `aria-label="..."`. 1 行 / button.
**局限**: 剩余 51 hit 来自其他 EP auto-generated `#el-id-*` (el-tooltip 弹窗 / el-popper / 其他 internal
组件), 这些是 EP 内部 id 不是项目代码, 真修法是全局 EP 升级或 pre-commit `axexclude:[aria-command-name]`,
需主指挥 W89+ 决策.
