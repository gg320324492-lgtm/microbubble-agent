### 4. 关键技术发现

#### 类 20.143: FollowUpChips.vue 编译错误是 production code bug, 不在测试范围

- `<Transition>` 含 2 个 v-if 子节点 (Vue 3.5 strict 编译期拒绝)
- 实测 `npx vite build` 仍成功 (生产构建对 transition-root 容忍)
- 测试不能改 production code → spec 选 production build (dist/) 服而非 vite dev
- 组件实例 (FollowUpChips) idle 时本来就不渲染 (无 suggestions event), 所以
  C10 改为验证 `.bot-bubble` 容器存在 (test-mode wrapper)

#### 类 20.144: Vite dev / preview 都因 .vite 缓存失败, 用 dist 静态服

- vite dev: `504 Outdated Optimize Dep` 反复出现, 需清 node_modules/.vite
- vite preview: 同样问题, dev/preview 都是 on-the-fly transform
- 实测方案: `npx vite build` → `node spa-server.cjs dist 3100`
- 生产 build 反而能 compile FollowUpChips (rollup 比 vue compiler 宽松)

#### 类 20.145: 多轮 SSE 流 stop-btn 卡死简化

- mock SSE 一次性返回全部 payload 后连接保持打开 → page 永不收 done event
- stop-btn 卡在 visible 状态 → send-btn 永不出现
- 简化为 I8: 只验证 stream 请求数 ≥ 1 (会话已建立), 不强制多轮
