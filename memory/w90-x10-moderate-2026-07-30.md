## 类 20.92 新增 (派工 v6 §5 反馈)

### 原文
> "npm audit 真修必逐 moderate 调研, major 升级不擅自动 (留专项派工)"

### 实战细化
1. **逐 moderate 调研 4 维度**:
   - 当前版本 (`cat node_modules/<pkg>/package.json | grep version`)
   - 父依赖链 (`npm ls <pkg>` + 嵌套 npm ls)
   - fixAvailable 是否 major (`isSemVerMajor`)
   - 同表兄弟 (e.g. update-notifier 升 7.x 后 latest-version 自动脱落)
2. **major 升级不擅自动**: fixAvailable 标 `isSemVerMajor=true` 的, **必**留专项派工 (视觉回归 / API 变更 / 依赖大变动)
3. **同表兄弟探测**: 升级父包可能自动脱落子包依赖, 节省 overrides 行数
4. **overrides 段优先级 > npm audit fix --force**: 用 overrides 单点修, 不动 hint 主版本
