## 派工 v6 §5 反馈 类 20.48 沉淀

> **类 20.48**: "a11y 真修必含: token 审计 + 多 component 分页修 + 硬断言 = 0"
>
> 三铁律合一:
> 1. **token 审计优先于 inline 改色**: 不能在 `.vue` scoped 块里临时改色 (破坏 6 主题自动适配 + 引发后续 a11y 漂移), 必须先审计 `variables.css` 的 `--color-text-secondary` / `--color-primary` / `--color-primary-bg` 等 token 对比度, 改 token 全局生效
> 2. **多 component 分页修**: 同一类 violation (color-contrast) 跨 5+ 个 component 时, 必须按 selector 分页修 (el-menu / sidebar / nut-tabbar / drive-tab / status-text), 不能"批量找色改色"导致遗漏
> 3. **硬断言 = 0 取代 baseline 比对**: `expect(violations.length).toBe(0)` 是真门禁, `toMatchSnapshot()` baseline 比对仅防止漂移 (W87-G-1 派工前提错配 — baseline 假绿是 axe "全绿可疑信号" 的典型陷阱)
