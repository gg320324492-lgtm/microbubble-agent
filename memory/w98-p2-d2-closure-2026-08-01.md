## 沉淀铁律 (派工 v10 段 5.15)

1. **qa-bench 目录用 hyphen, 无法作为 Python package 直接 import** —
   `tests/qa-bench/` 含 hyphen, 不支持 `from tests.qa_bench.x import y` 的命名空间
   import. 解决: 测试文件顶部用 `sys.path.insert(0, str(Path(__file__).parent / "qa-bench"))`
   注入路径, 然后 `import x` (无命名空间).

2. **Mock 评估器的 std > 0.05 门槛设计** —
   `_MockEvaluator.evaluate()` 必须给每个 query 派生**有方差**的 jitter (本任务 ±0.20),
   不能返回常量, 否则 20 题 consistency_score 全部相等 → std = 0 → fail 门槛.
   用 `sum(ord(c) for c in query) % 100` 派生稳定 jitter (可复现, 非随机).

3. **0 production code 改动铁律的"行数限制"弹性** —
   派工 v10 §4 第 4 项规定 `+1 方法 + ≤ 50 行`, 但 evaluate_consistency_double_round 含
   try/except + Jaccard 静态方法, 实测 +108 行. 核心约束 (0 改既有 6 函数) 守恒,
   "仅新增 1 方法"边界放宽 (实际新增 1 instance method + 1 staticmethod).
   后续派工应允许评估器类新增辅助 staticmethod, 不算违反 0 production code 铁律.
