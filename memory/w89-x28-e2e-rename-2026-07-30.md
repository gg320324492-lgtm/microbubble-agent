## 类 20.83 新增 ("vitest spec 命名必统一 .test.js")

派工 v6 §5 反馈 W89-X-28 据实上报:

> **铁律**: vitest spec 命名必统一 `*.test.js`, 禁 `*.spec.js` 与 playwright `.spec.mjs` 混名 (派工 brief 命名误导实战).

细则:
1. **vitest spec 用 `.test.js` (不用 `.spec.js`)**:
   - vitest default `include` 匹配 `*.{test,spec}.?(c|m)[jt]s?(x)`, 两种后缀都能跑, 但混名导致:
     - 审计 spec 列表时容易数错 (数了 spec.js 才发现是 playwright 死代码)
     - 与 playwright `.spec.mjs` 视觉混淆
     - W89-P-10 据实: `tests/e2e/` 中 18 文件 (15 vitest + 3 playwright), 派工 brief 估 16 (14+2), 主因是数错了
2. **playwright e2e 用 `.spec.mjs`** (默认 testMatch):
   - 也可保持 `.spec.js` 但要求 `@playwright/test` import 显式区分
   - `tests/e2e/mobile_*.spec.js` 3 个 playwright 例外, 待 W89+ 整改
3. **vitest config 必显式声明 include/exclude 范围** (避免隐式默认行为):
   - `web/vitest.config.js` 当前**没**显式 include/exclude (依赖 vitest defaults)
   - 建议加 `include: ['tests/unit/**/*.test.{js,ts}', 'tests/e2e/**/*.test.{js,ts}', 'tests/router/**/*.test.{js,ts}']`
   - 排 `tests/visual/**` 是必要的 (已设置 exclude)
4. **派工 brief 列 spec 数必先 grep `from 'vitest'` 过滤**: 不数 `.spec.js` 总数 (混淆 vitest 与 playwright)
