## 5 类 20 实战沉淀 (类 20.137-141)

### 类 20.137: 派工 brief 列出任务必先 `grep -rn "aria-label\|role="` 调研后据实修复缺口

- **实战**: W101 P3-A11Y 派工 brief 列出 9 个 chat 组件 a11y 任务, 实测 9/9 大部分已存在
- **派生**: 不先调研就批量实施 = 无意义重复劳动 + 锚点漂移
- **派工 v11 §3 E03 实战** 沿用, 不擅自扩也不擅自缩

### 类 20.138: focus-visible 散落样式应抽 variables.css token

- **实战**: NavRail / PlanSteps / ContentBriefDetail / ChatMessageActions 4 处 `:focus-visible { outline: 2px solid var(--color-primary); outline-offset: 2px; }` 字面重复
- **派生**: 抽 `--focus-outline-width` / `--focus-outline-color` / `--focus-outline-offset` 三 token, 改一处生效全部; 同时加全局 `:focus-visible` 兜底
- **dark mode 适配**: `[data-theme="dark"]` 切 `--color-primary-light` 提对比度 (浅色 outline 在深色背景上)

### 类 20.139: skip-link 必置于 template 第一个可聚焦元素 + hidden by default

- **实战**: ChatViewSSE `<a href="#chat-main" class="skip-link">` 置于 `<div class="chat-immersive">` 第一子元素 (在 network-banner 之前)
- **派生**: hidden by default 用 `transform: translateY(-200%)` + transition 150ms ease, focus-visible 时 `transform: translateY(0)`
- **WCAG 2.4.1 跳跃**: 屏幕阅读器 / 纯键盘用户首个 Tab 即跳到 #chat-main

### 类 20.140: 渲染列表卡片组件必须 role="list" + role="listitem"

- **实战**: KnowledgeRefBlock 修复前 `<div v-for>` 完全无 role, 屏幕阅读器识别不到 list 结构
- **派生**: `<div class="kb-ref">` 加 `role="list" aria-label="知识库引用列表"` + 每个 `<div class="ref-item">` 加 `role="listitem" tabindex="0" aria-label`
- **测试强制**: `KnowledgeRefBlock.test.js ① root role=list` + `② ref-item role=listitem` 双重断言

### 类 20.141: 复杂组件 aria-label 必含组件身份 + 状态, 不止状态

- **实战**: PlanSteps 修复前 aria-label="已完成" (仅状态), 屏幕阅读器朗读 "已完成" 不知哪步
- **派生**: 改 `aria-label="步骤 ${i+1}: ${step}${tool ? ', 使用工具 '+tool : ''}, ${status === 'done' ? '已完成' : status === 'running' ? '进行中' : '待执行'}"`
- **示例**: "步骤 2: 搜索知识库, 使用工具 search_knowledge, 已完成"
