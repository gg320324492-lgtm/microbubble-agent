## 3. 修法逐条 (类 20.100-104 实战)

### 3.1 aria-command-name ×15 — 1 处根因

**根因**: MainLayout.vue `<el-dropdown>` 内 `<div class="user-info">` 是 Element Plus trigger. el-tooltip 注入 `role="button"` 但内部内容是 `<el-avatar>` (只有 alt) + `<span class="user-role">{{ userRole }}</span>`. alt/innerText 在 axe 口径不算可访问名 (avatar 是装饰, user-role 文字 9px 太短且被 el-tooltip 包装吞掉).

**修法** (1 行 + 3 attr):
```vue
<div class="user-info" role="button" tabindex="0" aria-label="用户菜单" :aria-expanded="false" aria-haspopup="menu">
```
文件: `web/src/layouts/MainLayout.vue:102`

15 处全消除 (× 3 mobile projects × 5 routes).

### 3.2 scrollable-region-focusable ×6 — 2 处根因

**根因**: `.session-list` (Vue ref 容器) + `.folder-tree` 都是 `overflow-y: auto` div 但没 `tabindex`, axe 报告 "scrollable region without focusable content".

**W89-X-20 #3 教训**: 当时用 `role="list" tabindex="0" aria-label="..."`. 我先沿用, 跑了发现触发 **`aria-required-children [critical] ×3`** (子元素不是 role=listitem).

**修法 (类 20.104)** — 不要 `role`, 只 `tabindex` + `aria-label`:
```vue
<div class="session-list" tabindex="0" aria-label="会话列表">  <!-- SessionSidebar.vue:228 -->
<div class="folder-tree drive-folder-tree" tabindex="0" aria-label="文件夹树">  <!-- FolderTree.vue:21 -->
```
文件 2 个: `web/src/components/chat/SessionSidebar.vue`, `web/src/components/drive/FolderTree.vue`.

**类 20.104 沉淀**: "scrollable-region 用 role+tabindex 会触发 aria-required-children** — 实测: 单纯 tabindex=0 + aria-label 即满足, 不写 role". 派工 brief 推的 "role='tree' / role='list'" 是字面写, 但 children 不是 listitem/treeitem 时反而坏。

### 3.3 残留 color-contrast 253 → 0 — 5 处根因 + 5 文件

W91-X-19 已修了 72 (通过 variables.css token + 选择器层 `:root { ... }` 注入覆盖). dist (W91 时 build 阻断) 未刷新. 我这边重 build → 修了剩下 6 处:

| 选择器 | 文件 | 原色 → 新 token | 比值 |
|---|---|---|---|
| `.mode-option.active` color | ThinkingModeSwitch.vue | `--color-primary` → `--color-primary-text` | 2.56 → 5.37 |
| `[data-theme="dark"] .mode-option.active` color | ThinkingModeSwitch.vue | `--color-primary` → `--color-primary-text` (dark 也定义) | — |
| `:deep(.nut-tabbar-item:not(.nut-tabbar-item__icon--unactive))` color | TabBar.vue | `--color-primary` → `--color-primary-text` | 2.31 → 4.84 |
| `.drive-tab-btn.active` color | MobileDriveView.vue | `--color-primary` → `--color-primary-text` | 2.31 → 4.84 |
| `.folder-chip.active` background-color (light + dark) | MobileDriveView.vue | `--color-primary` → `--color-primary-strong` | 2.56 → 5.37 |
| `.trash-hint` color | MobileTaskTrash.vue | `var(--color-warning)` → `--color-warning-text` | 2.03 → 5.89 |
| `.dfcv-tab-btn.active` color | DesktopFileCommentsView.vue | `--color-primary` → `--color-primary-text` | 2.31 → 4.84 |
| `.dfcv-empty .empty-hint` | DesktopFileCommentsView.vue | `opacity: 0.75` → 实色 `--color-text-secondary` (类 20.103 — axe 按合成后判) | 2.97 → 4.96 |
| `.dci-hint` color | DesktopCommentInput.vue | `--color-text-placeholder` → `--color-text-secondary` | 1.74 → 4.96 |

**类 20.102 加固实战**: scoped style 里直接写 `color: var(--color-primary)` 是 42 个文件 (grep 实测), 模式化错误. W91-X-19 用 `:root { ... }` 高优级覆盖一部分, 但 `.dfcv-tab-btn.active` 等加了 data-v-hash 后 specificity 更高, 全局 inject 仍让步. **最稳做法**: 单文件改 source token, 不依赖全文件级修补.

**类 20.103 加固实战**: `.dfcv-empty .empty-hint` 实色 4.96 通过, 但 W91-X-19 仍被 axe 报 — 因 `opacity:0.75` 把 `--color-text-secondary #6B6E76` 合成稀释成 `#8e9097`, 比值回到 2.97. **取消 opacity 改实色**才生效.
