#### B. `mobile_swipe_gesture.spec.js` — 6 test, **0/6 PASS (结构性失败)**

```
$ SKIP_DB_SETUP=1 timeout 90 npx playwright test tests/e2e/mobile_swipe_gesture.spec.js --config=playwright.config.js -c tests/e2e

Cannot use({ defaultBrowserType }) in a describe group, because it forces a new worker.
Make it top-level in the test file or put in the configuration file.
   at mobile_swipe_gesture.spec.js:49
> 49 |   test.use({ ...devices['iPhone 13'], hasTouch: true, isMobile: true })
```

**所有 6 test 全报**相同错误, 3 个 describe 块 (lines 48, 114, 162) 都在 describe 内部直接 `test.use({...})`.

**根因**:
- playwright 规则: `test.use()` 只允许 top-level 或 config, **禁止**在 `test.describe()` 块内 (因为 `test.use` 强制新 worker, 描述组共享 worker, 冲突)
- 这是**结构性 pre-existing bug**, 不是环境问题
- 修复方案: 把 3 个 `test.use({...})` 提到文件顶层, 或移到 `playwright.config.js` projects 段

**代码本身**:
- `const { test, expect, devices } = require('@playwright/test')` (line 11) — CommonJS, 注意
- simulateSwipe helper (lines 17-43): mouse.move/down/up 模拟触摸, Playwright 不支持 multi-touch 用 mouse 兜底
- 6 test 涉及 Drive / Chat / Knowledge 页 + navigator.vibrate mock

**结论**: **代码有 bug + 死代码** (vitest 也跑不动它 — CommonJS require 触发 import error, vitest results.json `duration:0,failed:true`).
