**根因** (`web/tests/visual/a11y/axe-config.mjs:injectAuth`):

```js
export async function injectAuth(page, baseUrl) {
  const token = process.env.TEST_TOKEN
  if (!token) return false          // ← 静默降级, 不抛错
  ...
}
```

`TEST_TOKEN` 缺失 → `injectAuth` 返回 `false` → `page.goto('/chat')` 被 `router/index.js:269` 守卫
(`localStorage.getItem('access_token')`) 重定向到 `/login` → axe 扫的是**登录页**, 不是目标页面。
spec 照常 `toMatchSnapshot()` 写盘, 于是 25 份 baseline 全部记录成登录页的 a11y 结果。

登录页只有一个表单, 天然 a11y 干净 → **`violations: 0` 是假绿**, 完美命中:
- **类 20.25** "a11y 测试必先 baseline, 全绿是可疑信号"
- **类 20.84** "a11y baseline 必入 git + 必在登录态生成"
