## 派工 v6 §5 反馈: 类 20.71 沉淀

### 类 20.71: 生产白屏 1 行修法必 composable 必 import

**触发条件**: 任何 Vue 3 `<script setup>` 组件在 `setup()` 体内调 composable (以 `useXxx` 命名的函数) 但缺 `import` 语句。

**典型症状**:
- 浏览器控制台: `ReferenceError: useXxx is not defined` 或 `useXxx is not defined` (setup 体内)
- 生产环境整页白屏 (mount 失败)
- dev 模式 (Vite HMR) 报同错, 但因 HMR 可恢复, 容易被忽略
- e2e: `pageerror: <error>` 持续 PAGEERROR, 全部 case 阻断

**正确修法**: 在 `<script setup>` 顶部 import 段加 1 行 (按字母序插入对应 `@/composables/useXxx` 模块, 复用现有 import 模式)。

**预防铁律 (5 条)**:
1. **写 composable 调用前先 import** — 不要假设 IDE/Vite 自动 import 会兜底, setup 体内手动写是 Vue 3 唯一合法模式
2. **参考同 wave 兄弟组件** — 同一类移动端组件 (MobileCommentInput 已正确 import useMobileKeyboard) 是直接参考
3. **e2e 必须设静态 import 门禁** — 任何 vue 组件 必加 e2e 断言 `import { ... useXxx ... } from '@/composables/useXxx'` + `useXxx()` 调用
4. **dev 模式报错 ≠ HMR 兜底** — Vite dev 抛 ReferenceError 不代表 prod build 也会暴露, prod build minify 后报错更隐蔽
5. **1 行修法 ≠ 0 测试** — 紧急 P0 修法后必须加 e2e 硬门禁防回归, 不能"补完就跑"
