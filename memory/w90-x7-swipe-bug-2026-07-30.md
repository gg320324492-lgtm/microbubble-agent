## 7. 派工 v6 §5 反馈 类 20.89 沉淀

> **类 20.89**: "Playwright `test.use` 必在 `projects[].use` 配置, 禁 spec 内 file scope 顶层 / describe 内 (W89-X-14 拦截 + W90-X-7 真修实战)"

要点:
1. **1.61 完全禁 spec 内 `test.use`** (无论 file scope 还是 describe 内), 仅 `projects[].use` 合法
2. **1.62** 允许 file scope 顶层 (在 require 之后 / describe 之前), 但**禁 describe 内** —— 派工 brief 推荐的"顶层"在 1.61 下也不工作
3. **修法**: 把 device profile 提取到 `playwright.config.js` 新 project,spec 内完全清空 `test.use` —— 这在 1.61 / 1.62 双版本下都稳定
4. **e2e 加固**: 守卫 `tests/swipe_x7/test_no_test_use_in_describe.py` 双向拦截
5. **避免双版本陷阱**: spec 跑的 Playwright 必须与 config 跑的 Playwright 一致;任务 worktree 缺
   `web/node_modules` 时,`require('@playwright/test')` 会从根 hoist 解析,与 CLI 期望版本冲突
6. **未来加固建议 (X-25 整合时)**:
   - `playwright.config.js` 加 `webServer` (CLAUDE.md v77 P2.6-D) 让 `npm run test:visual` 自带 dev server
