2. `regenerate(msg)` handler (向前找 user content, 复用 sendMessage):
   ```js
   async function regenerate(msg: ChatMessage) {
     if (isCurrentSessionSending.value) {
       ElMessage.warning('当前正在生成中，请先点 ⏹ 停止')
       return
     }
     const list = messages.value || []
     const idx = list.findIndex((m) => m.id === msg.id)
     if (idx === -1) { ElMessage.error('找不到原始消息，无法重新生成'); return }
     let userContent = ''
     for (let i = idx - 1; i >= 0; i--) {
       const m = list[i]
       if (m?.role === 'user' && (m.content || '').trim()) { userContent = (m.content || '').trim(); break }
     }
     if (!userContent) { ElMessage.warning('找不到对应的用户提问，无法重新生成'); return }
     ElMessage.info('正在重新生成...')
     await sendMessage(userContent)
   }
   ```

3. `copyMessage(msg)` handler (clipboard API + execCommand 降级):
   ```js
   async function copyMessage(msg: ChatMessage) {
     const text = (msg?.content || '').trim()
     if (!text) return
     try {
       if (navigator?.clipboard?.writeText) {
         await navigator.clipboard.writeText(text); ElMessage.success('已复制'); return
       }
       // 降级 execCommand
       const ta = document.createElement('textarea'); ta.value = text
       ta.style.position = 'fixed'; ta.style.opacity = '0'
       document.body.appendChild(ta); ta.select()
       const ok = document.execCommand('copy'); document.body.removeChild(ta)
       if (ok) ElMessage.success('已复制'); else ElMessage.error('复制失败，请手动选择文本')
     } catch (e) { console.error('[copyMessage] failed', e); ElMessage.error('复制失败，请手动选择文本') }
   }
   ```

## 四、5 件套守恒 + 类 20 #21 派生

**类 20 #21 派生 (派工前提铁律 12 + 实战沉淀)**:
> **"ChatMessageActions 重生成逻辑必须向前找 user content, 不能信任 msg.id 在 messages[] 中的索引稳定性"**

- **事故**: 实现 regenerate 时若直接用 `messages.value.findIndex(m => m.id === msg.id)`, 在多会话并行场景下 (`useChatStream.messagesBySession`) 会拿到错误 session 的 messages
- **正确做法**: `useChatStream` 已暴露当前 `messages` ref (computed over current session), 直接 `messages.value.findIndex` 即可
- **边界**: 若目标 msg 不在当前 session (跨 session regenerate), 找不到 → ElMessage 提示 + return
- **再次边界**: 若目标 msg 是当前 session 第一条 (没有前置 user), 找不到 → ElMessage 提示 + return
- **强约束**: sendMessage 复用即可, 不需要新方法 (复用 useChatStream.sendMessage(text) → 触发 SSE + 自动滚动 + loading + 持久化)

## 五、回归风险

- **regenerate 期间 SSE 流式**: regenerating 状态 3s 自动复位 (防御性), 期间再次点击 disabled; 真实 SSE 完成时新气泡会重新挂组件 → 状态自然刷新
- **copy 期间重复点击**: copying 状态 1.5s 自动复位; clipboard API 失败时 ElMessage 错误
- **移动端 LongPress 冲突**: `.stop` 修饰符防止 emit 冒泡到 LongPressWrapper
- **桌面 hover 闪烁**: opacity 0→1 200ms ease + focus-within 持久 (键盘 a11y)
- **dark mode 文字对比度**: 用 `--color-text-secondary` (对齐 FeedbackButtons), 高亮用 `--color-primary` 暖橙
- **vitest 既有失败**: ThinkingCapsule.test.ts 1 case + assistantPhase.test.ts 19 case 已有回归 (与本次改动无关, 是 W99/W100 历史 baseline 漂移, 不引入新 regression)
