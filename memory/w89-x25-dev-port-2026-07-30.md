### 端口漂移历史 (类 20.80 根因)

- 早期 vite dev 跑 3100 → 后来改 3004 → 现在 3000 (package.json "dev" 当前值)
- spec 历史未同步更新, 每个老 spec 都锁死当时 dev port
- vite dev `--strictPort=false` (package.json:6) 让 port 占用自动 fallback,
  但 spec 不知道 fallback 到哪个 port

### 修法

**方案 A (X-25 选)**: 统一兜底 URL 为 `http://localhost:3000`, 与 `package.json`
`"dev": "npx vite --port 3000 --strictPort=false"` 完全对齐。优点: 单点真相,
未来 dev port 再变只需改 1 处。

**方案 B (备选, 未选)**: 兜底 `http://localhost:3000` 但保留各 spec 独立的
`BASE_URL` 常量声明。问题: 还是硬编码。

**方案 C (备选, 未选)**: 不设兜底, 强制要求环境变量。问题: 本地 dev 体验
差, CI runner 没 BASE_URL 就跑不起来。

派工 brief v3 双锚定 → A 方案: 环境变量 + 兜底 + 单点真相。

### 新增守恒测试 (4 个 case)

`tests/dev_port_x25/test_base_url.py`:

   (desktop × 2 + mobile × 1 + a11y × 1), 必含 `process.env.BASE_URL`。
3. **`test_playwright_config_base_url_uses_env`** —
   `web/playwright.config.js` `baseURL` 必 `process.env.BASE_URL`。
4. **`test_package_json_dev_port_aligned`** — `package.json` `"dev"` script
   必含 `--port 3000`。
